# INVminer v2.2.0.8

## Changes

- Optimize Proxima BLAKE2b search for validated sparse-tail jobs on Turing, Ampere, Ada and Blackwell GPUs, with measured gains on CMP40HX, CMP50HX and RTX 5060 Ti.

## Compatibility

**Proxima upgrade-6 only, 0% developer fee. Linux/HiveOS and Windows x64.** Keep existing holder/account IDs, ordered pool endpoints and flight-sheet arguments. The fast path is selected automatically when its complete zero-tail and nonce-position checks pass; other jobs retain the existing path. No clock, power or fan changes are applied.

**The speed gain requires a matching task layout, not merely a 504-byte length.** Our pool's currently observed 330-byte jobs do not qualify for this fast path. This release does not change pool templates and does not claim higher current-pool production or a lead over a competing miner.

Ordered endpoint failover, primary recovery, rotate mode, GPU selection, statistics and low-CPU waiting remain supported. NOID/QUAN use their separate package. The old Proxima VRF algorithm/private gateway is incompatible. Preserve old wallet/identity backups; these packages do not migrate or delete them.

## Tested GPU hashrates / 已测试显卡算力

Matched 504-byte sparse-tail **offline kernel** comparison, same physical cards and unchanged settings. A → B → B → A, with 5 s warm-up and about 20 s measured per phase, cooled to at most 55 C before each phase. Baseline modules are the released 2.2.0.4 Linux / 2.2.0.5 Windows modules; new modules are byte-identical to those bundled in this release. Rates are completed nonce attempts divided by elapsed wall time, not pool estimates.

|---|---:|---|---:|---:|---:|---:|
| CMP40HX | 2 | 580.173.02 | 125 W | 2.131, 2.117 | 2.300, 2.286 | +7.95%, +8.01% |
| CMP50HX | 1 | 580.173.02 | 225 W | 3.460 | 3.748 | +8.31% |
| RTX 5060 Ti | 1 | 580.173.02 | 180 W | 3.796 | 4.202 | +10.69% |

These are cooled short windows, not sustained hot-state throughput. An earlier longer run reached the 80 C test guard on CMP50HX and was stopped; it is not counted as a passing comparison. The gains above do not apply to arbitrary jobs or establish earnings, energy efficiency, long-term stability, or performance on untested models.

## Linux / HiveOS setup

Installation URL: `https://github.com/getrigeos/INVminer-Release/releases/download/v2.2.0.8/invminer-2.2.0.8.tar.gz`

Coin: Proxima; custom miner name: `invminer`; wallet: registered 64-hex holder/account ID; wallet template: `%WAL%.%WORKER_NAME%`; password: `x`; extra arguments: `--coin proxima`.

Pool URL, one per line, in this order:

```text
stratum+ssl://global.innovlab.cc:19701
stratum+ssl://eu3.innovlab.cc:19701
```

Native Linux:

```bash
./invminer --coin proxima -o stratum+ssl://global.innovlab.cc:19701 -o stratum+ssl://eu3.innovlab.cc:19701 -u YOUR_REGISTERED_64_HEX_ID.rig1 -p x
```

All visible supported GPUs start by default; `--devices 0,2` selects a subset. Default `primary` probes and returns to the first recovered endpoint; `--pool-failover-mode rotate` stays on a healthy backup. HiveOS installation, upgrade from 2.2.0.4, restart and six-card callbacks were physically tested; the cloud flight-sheet UI was not operated.

Linux requires glibc 2.31+. CUDA12 requires Driver API 12.0+; RTX 50 series additionally needs a suitable R570+ driver. CUDA13 requires Driver API 13.0+ /R580+. HiveOS selects the compatible bundled executable automatically.

## Windows setup

Extract the entire ZIP, open `invminer`, run `start-proxima.bat`, and enter your registered 64-hex holder/account ID. Never enter a private key or seed. Default worker: `winrig`. The launcher uses the ordered pools above.

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\start-proxima.ps1 -Account YOUR_REGISTERED_64_HEX_ID -Worker winrig -Devices 0
```

Windows requires an NVIDIA driver supporting CUDA12; no CUDA Toolkit, Python or Go installation is needed. The launcher pauses at 65 C, resumes at 60 C and stops at 70 C; `-TempLimit` and `-TempStop` customize these thresholds. Existing power/clock settings are preserved; the 100W test cap is not automatically applied. Statistics: `http://127.0.0.1:4068/stats`. Ctrl+C stops mining.

Mining TLS encrypts traffic and accepts self-signed pool certificates. Download HTTPS keeps normal certificate verification. Previous immutable Linux/HiveOS 2.2.0.4 and Windows 2.2.0.5 remain available for rollback.
