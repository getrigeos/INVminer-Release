# INVminer v0.1.50

## GPU command

```bash
./invminer --coin noid \
  -o stratum+ssl://stratum.innovlab.cc:19601 \
  -u YOUR_NOID_ADDRESS.RIG_NAME \
  -p x
```

## CPU-only command

```bash
./invminer --coin noid --cpu-only \
  -o stratum+ssl://stratum.innovlab.cc:19601 \
  -u YOUR_NOID_ADDRESS.RIG_NAME \
  -p x
```

This release supports only NOID and embeds only NOID CUDA modules. The
executable is always named `invminer`, and the coin is selected explicitly with
`--coin noid`.

> **Binary-only risk:** this release may be incompatible with a particular GPU,
> CPU, driver, OS, or future pool state. Source is not provided, so users cannot
> independently rebuild, audit, or patch it and must decide whether to trust the
> executable and published checksums. The software is provided without warranty.

maximum required GNU C Library symbol is `GLIBC_2.30`; CUDA and NVML are loaded

To select one GPU, add `--device 0` to the GPU command. With no device list, all
supported GPUs use one shared user-pool connection and non-overlapping search
ranges. Mining geometry, CPU thread count, batch size, ISA flags, and
`--state-dir` are not required in the normal command.

## CUDA compatibility

| GPU family | SM | CUDA 12 | CUDA 13 | v0.1.50 status |
|---|---:|---|---|---|
| Turing / CMP | `sm_75` | Supported | Unsupported | Architecture lane included; use CUDA 12 |
| RTX 30 | `sm_86` | Supported | Supported | Architecture lanes included; not physically rerun for this release |
| RTX 40 | `sm_89` | Supported | Supported | Both exact assets physically tested on RTX 4070 / driver 580.178.04 |
| RTX 50 | `sm_120` | Supported | Supported | Architecture lanes included; not physically rerun for this release |

The RTX 4070 gate used default board controls and no clock arguments. Both exact
assets loaded their native SM89 module, passed CPU/GPU exact self-tests, and
submitted accepted shares with no resolved rejected shares. The canonical
InnovLab endpoint was unavailable from the gate host, so the already-authorized
WebPKI compatibility gate was used; its endpoint and test identity are not
published. CPU-only mode also passed its exact AVX-512 self-test.

## HiveOS

The HiveOS archives contain:

```text
invminer/
  invminer
  h-manifest.conf
  h-config.sh
  h-run.sh
  h-stats.sh
  h-readme.md
```

In a Custom Miner flight sheet set Hash algorithm to `noid`, Pool URL to the TLS
endpoint above, Template to `%WAL%.%WORKER_NAME%`, and Pass to `x`. The adapter
maps them to `invminer --coin noid ...` without `eval` and reports aggregate and
per-GPU statistics through the loopback API.

## Developer fee and process behavior

NOID uses a 5% developer fee measured from effective mining time. Waiting,
connection preparation failures, and unavailable fee work are not charged. The
payout identity is not printed in normal logs or public documentation.

Extracting or running the package does not install or enable a systemd service,
cron job, scheduled task, login/startup item, registry Run key, or container
restart policy. Optional hardware controls remain disabled unless explicitly
provided.

HiveOS 請使用與驅動相符的 HiveOS 壓縮包，在 Custom Miner 飛行表填入：Hash algorithm
