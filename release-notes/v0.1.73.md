# INVminer v0.1.73

## GPU command

```bash
./invminer --coin noid -o stratum+ssl://eu.innovlab.cc:19601 -u YOUR_NOID_ADDRESS.RIG_NAME
```

## CPU-only command

```bash
./invminer --coin noid --cpu-only -o stratum+ssl://eu.innovlab.cc:19601 -u YOUR_NOID_ADDRESS.RIG_NAME
```

The worker suffix and `-p/--pass` are optional. Public binaries accept the approved
`innovlab.cc` and `01pool.com` TLS domain boundary. TLS certificate-chain and
original-hostname verification remain mandatory.

> **Binary-only risk:** this release may not work with every GPU, CPU, driver,
> OS, or future pool state. Source is not provided, so users cannot independently
> rebuild, audit, or patch it and must decide whether to trust the executable and
> published checksums. The software is provided without warranty.

## NOID developer fee

The NOID developer fee is now **1% of effective mining time**. Each 100 minutes of
chargeable GPU work consists of 99 minutes for the user and one minute for the
developer. Connection setup, waiting, and unavailable fee work are not charged.

## Multi-pool recovery

Repeat `--pool`, or use a comma-separated list, to configure ordered backup pools:

```bash
./invminer --coin noid --pool stratum+ssl://eu.innovlab.cc:19601 --pool stratum+ssl://hk.innovlab.cc:19601 --user YOUR_NOID_ADDRESS.RIG_NAME
```

INVminer keeps one steady mining connection. It rotates after bounded failures and
uses only short-lived probes before returning to a recovered primary; it does not
maintain permanent sessions to every backup. DNS, certificate, and pool-service
failures are retried in the same process and mining resumes after the service is fixed.

The exact public HiveOS archive completed the EU→HK2→US→RU fault sequence with
70 accepted, 1 stale, 0 rejected and four reconnects. It returned to the primary
with the same PID, kept one steady mining connection, and passed `h-stats`.

## HiveOS

- Miner name: `invminer`
- Installation URL: `https://github.com/getrigeos/INVminer-Release/releases/download/v0.1.73/invminer-0.1.73.tar.gz`
- Hash algorithm: `noid`
- Pool URL: `stratum+ssl://eu.innovlab.cc:19601`
- Wallet template: `%WAL%.%WORKER_NAME%`
- Pass: leave empty
- Extra config arguments: leave empty for default controls

The CUDA 12/HiveOS package embeds reviewed native lanes for `sm_75`, `sm_80`,
`sm_86`, `sm_89`, and `sm_120`, including its CUDA 12.2 compatibility fallback.

### HiveOS foreground troubleshooting

Use this only when normal startup is abnormal. It stops the managed miner when
present, creates a fresh temporary directory, and runs the current package in the
foreground. Replace only the wallet address; the worker suffix is optional.

`(miner stop || true) && cd "$(mktemp -d /tmp/173invminer.XXXXXX)" && wget -O invminer-0.1.73.tar.gz https://github.com/getrigeos/INVminer-Release/releases/download/v0.1.73/invminer-0.1.73.tar.gz && tar -xzf invminer-0.1.73.tar.gz && cd invminer && chmod +x invminer && ./invminer --coin noid --pool stratum+ssl://eu.innovlab.cc:19601 --user YOUR_NOID_ADDRESS --pass x`

### Manual upgrade for older HiveOS installations

Only some older HiveOS installations need this manual replacement. Use it only when HiveOS does not update the installed custom miner after the Installation URL is changed to this release.

```bash
miner stop && cd /tmp && rm -rf invminer && rm -f invminer-0.1.73.tar.gz && wget -O invminer-0.1.73.tar.gz https://github.com/getrigeos/INVminer-Release/releases/download/v0.1.73/invminer-0.1.73.tar.gz && tar -xzf invminer-0.1.73.tar.gz && mkdir -p /hive/miners/custom/invminer && rm -f /hive/miners/custom/invminer/invminer && cp -af invminer/. /hive/miners/custom/invminer/ && chmod +x /hive/miners/custom/invminer/invminer /hive/miners/custom/invminer/h-*.sh && /hive/miners/custom/invminer/invminer --version && miner start
```
