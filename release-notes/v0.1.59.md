# INVminer v0.1.59 Hotfix

## GPU command

```bash
./invminer --coin noid \
  -o stratum+ssl://eu.innovlab.cc:19601 \
  -u YOUR_NOID_ADDRESS.RIG_NAME \
  -p x
```

Use only an official NOID TLS endpoint: `eu.innovlab.cc:19601` (Europe) or
`hk.innovlab.cc:19601` (Hong Kong). This example defaults to Europe; replace
only the hostname to use Hong Kong.

## Ampere / HiveOS compatibility hotfix

The CUDA 12 and canonical HiveOS assets now recover automatically when a driver
rejects the preferred native `sm_86` image with errors such as `no kernel
image`. The miner then loads its embedded CUDA 12.2 native `sm_86`
compatibility profile. No alternate HiveOS package, environment variable, or
manual module selection is required.

This is a loader compatibility fix. The reviewed modules for `sm_75`, `sm_89`,
and `sm_120` are retained unchanged. The affected RTX 3070 Ti was not
physically available for this release, so that exact card is explicitly not
claimed as retested. The final package contains native `sm_86` images in both
the preferred and fallback modules, and both module digests passed the private
release gate.

member, version, argv, module-marker, dashboard-statistics, and live TLS pool
gates. Disconnect/failover injection and the GPU models marked “No” above were
not rerun for this narrow compatibility hotfix.

## Native NVIDIA controls

The existing `--power-limit`, `--lock-core`, `--locked-core-clock`,
`--lock-mem`, and `--core-clock-offset` controls are retained. They are not
required for the Ampere fallback. Unsupported values, missing permissions, or
unavailable optional tools produce a warning and mining continues at the
verified original/default state; an unsafe partial rollback stops mining.

## HiveOS

- Miner name: `invminer`
- Installation URL: `https://github.com/getrigeos/INVminer-Release/releases/download/v0.1.59/invminer-0.1.59.tar.gz`
- Hash algorithm: `noid`
- Pool URL: `stratum+ssl://eu.innovlab.cc:19601`
- Wallet and worker template: `%WAL%.%WORKER_NAME%`
- Pass: `x`
- Extra config arguments: leave empty unless ordinary runtime options are needed

The HiveOS archive must remain `<miner-name>-<version>.tar.gz`; do not add the
tag `v`, platform, architecture, HiveOS, or CUDA labels.

### Manual upgrade for older HiveOS installations

Only some older HiveOS installations need this manual replacement. Use it only when HiveOS does not update the installed custom miner after the Installation URL is changed to this release.

```bash
miner stop && cd /tmp && rm -rf invminer && rm -f invminer-0.1.59.tar.gz && wget -O invminer-0.1.59.tar.gz https://github.com/getrigeos/INVminer-Release/releases/download/v0.1.59/invminer-0.1.59.tar.gz && tar -xzf invminer-0.1.59.tar.gz && mkdir -p /hive/miners/custom/invminer && rm -f /hive/miners/custom/invminer/invminer && cp -af invminer/. /hive/miners/custom/invminer/ && chmod +x /hive/miners/custom/invminer/invminer /hive/miners/custom/invminer/h-*.sh && /hive/miners/custom/invminer/invminer --version && miner start
```

### 舊版 HiveOS 手動升級

僅部分舊版 HiveOS 需要此手動覆蓋；只有在更新 Installation URL 後仍未替換已安裝的 Custom Miner 時才執行。

# INVminer v0.1.59（繁體中文）

本版修正部分 Ampere／HiveOS 主機啟動時出現 `no kernel image` 的問題。CUDA 12
套件會先載入既有高效能 `sm_86` 模組；若驅動判定映像不相容，程式會自動切換到內嵌的
CUDA 12.2 原生 `sm_86` 相容模組，不需更換套件、設定環境變數或手動指定模組。

RTX 3070 Ti 本版沒有實卡可供重測，因此不宣稱已完成該型號的實機驗收；最終套件中的兩個
原生 `sm_86` 映像、雜湊及自動 fallback 路徑已通過發布門禁。RTX 4070 已用兩個最終
二進位及最終 HiveOS 套件完成自檢、受控運行、TLS 真池與 HiveOS 統計驗收。其餘架構的
既有審核模組保持不變。

HiveOS 請使用 `invminer-0.1.59.tar.gz`；Miner name 填 `invminer`、Hash algorithm
填 `noid`、Template 填 `%WAL%.%WORKER_NAME%`、Pass 填 `x`，Extra config arguments
預設留空。官方節點僅為 `eu.innovlab.cc:19601` 或 `hk.innovlab.cc:19601`。

NOID 開發費為有效挖礦時間的 5%。套件不會自行建立或啟用開機服務、cron、排程、登入
啟動項或容器重啟策略；本倉庫僅提供閉源二進位，使用者需自行評估相容性與信任風險。
