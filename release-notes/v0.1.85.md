# INVminer v0.1.85

## GPU command

```bash
./invminer --coin quan -o stratum+ssl://eu2.innovlab.cc:17601 -u YOUR_QUANTUS_ADDRESS[.WORKER]
```

## CPU-only command

```bash
./invminer --coin noid --cpu-only -o stratum+ssl://eu.innovlab.cc:19601 -u YOUR_NOID_ADDRESS[.WORKER]
```

## NOID GPU command

```bash
./invminer --coin noid -o stratum+ssl://eu.innovlab.cc:19601 -u YOUR_NOID_ADDRESS[.WORKER]
```

`--coin noid` or `--coin quan` is required. The worker suffix and `--pass` are
optional; an omitted password uses the compatible value `x`.

> **Binary-only risk:** this release may not work with every GPU, CPU, driver,
> OS, or future pool state. Source is not provided, so users cannot independently
> rebuild, audit, or patch it. The software is provided without warranty.

## Changes

- The CUDA 12 build now recovers automatically when a Driver 535 generation
  host rejects a newer NOID SM89 device image. It selects the reviewed CUDA 12.2
  native fallback before GPU work begins.
- QUAN keeps its qualified Full256 paths for RTX 4070, RTX 4090, RTX 5090,
  CMP 40HX, CMP 50HX, A40 and other supported NVIDIA devices.
- The release process now requires both CUDA 12 and CUDA 13 physical GPU gates.
  A release is blocked when either flavor lacks native self-test, positive
  per-device work, authenticated TLS mining, or an accepted share.
- Quanpool, Kryptex, LuckyPool and compatible QUAN QUIC, TCP and TLS pools remain
  selectable. Hostnames are resolved for every connection; provider IP addresses
  are not embedded.
- A HiveOS host-and-port-only Pool URL defaults to authenticated TLS. Plaintext
  requires an explicit `stratum+tcp://` URL.
- The disclosed QUAN developer fee remains 2% and uses the official Quanpool
  hostname. NOID remains at 1%.

## Validation and boundaries

- Public and companion CUDA 12 and CUDA 13 binaries were each built twice from
  one frozen source commit in an offline pinned environment. Matching binaries
  and archives were byte-identical.
- The public CUDA 12 binary passed exact NOID CPU/GPU self-tests on six RTX 4070
  SUPER GPUs with Driver 535. Every device selected the reviewed native fallback.
- The exact public CUDA 12/HiveOS archive passed QUAN native self-tests and live
  accepted-share accounting on all six GPUs. Its NOID HiveOS test retained one
  process across the complete four-pool TLS failover chain, returned to the
  primary pool, and produced valid `h-stats`.
- The public CUDA 13 binary passed native self-test and live authenticated TLS
  mining on RTX 5090.
- This release does not publish a numerical performance claim.
- Linux x86_64 requires glibc 2.30 or newer. Use the CUDA 12 package for broad
  driver compatibility. RTX 50 series requires a Blackwell-capable driver.

## HiveOS flight sheet

- Miner: Custom → `invminer`
- Installation URL: `https://github.com/getrigeos/INVminer-Release/releases/download/v0.1.85/invminer-0.1.85.tar.gz`
- Coin: Custom
- Hash algorithm: `quan` for QUAN or `noid` for NOID
- QUAN Pool URL: `eu2.innovlab.cc:17601` (host-and-port-only defaults to authenticated TLS)
- NOID Pool URL: `eu.innovlab.cc:19601` (host-and-port-only defaults to authenticated TLS)
- Wallet template: `%WAL%.%WORKER_NAME%`
- Pass: `x`
- Extra config arguments: empty by default; add only optional INVminer flags

All visible GPUs are used automatically; do not add `--devices` unless you want
an explicit subset.

### Foreground troubleshooting

For abnormal startup only: stop the managed miner if present, download into a
new random directory, and show errors in the foreground. Replace the wallet
address and select the intended coin after startup is confirmed.

`(miner stop || true) && cd "$(mktemp -d /tmp/185invminer.XXXXXX)" && wget -O invminer-0.1.85.tar.gz https://github.com/getrigeos/INVminer-Release/releases/download/v0.1.85/invminer-0.1.85.tar.gz && tar -xzf invminer-0.1.85.tar.gz && cd invminer && chmod +x invminer && ./invminer --coin noid --pool stratum+ssl://eu.innovlab.cc:19601 --user YOUR_NOID_ADDRESS --pass x`

### Older HiveOS manual replacement

Only some older HiveOS installations need this manual replacement. Use it only when HiveOS does not update the installed custom miner after the Installation URL is changed to this release.

```bash
miner stop && cd /tmp && rm -rf invminer && rm -f invminer-0.1.85.tar.gz && wget -O invminer-0.1.85.tar.gz https://github.com/getrigeos/INVminer-Release/releases/download/v0.1.85/invminer-0.1.85.tar.gz && tar -xzf invminer-0.1.85.tar.gz && mkdir -p /hive/miners/custom/invminer && rm -f /hive/miners/custom/invminer/invminer && cp -af invminer/. /hive/miners/custom/invminer/ && chmod +x /hive/miners/custom/invminer/invminer /hive/miners/custom/invminer/h-*.sh && /hive/miners/custom/invminer/invminer --version && miner start
```

## 繁體中文

v0.1.85 修正 CUDA 12 套件在 Driver 535 世代的 SM89 顯卡上載入 NOID 模組時的
相容性問題。若驅動拒絕較新的映像，礦工會在 GPU 工作開始前自動選擇已審查的
CUDA 12.2 原生回退模組。QUAN 保留已驗收的 Full256 路徑、相容礦池協議與 2%
開發費；使用者選擇的礦池仍保持獨立，供應商 IP 不會寫入程式。

正式 CUDA 12 套件已在 Driver 535 的六張 RTX 4070 SUPER 上通過 NOID 精確自檢、
QUAN 多卡實池與 HiveOS 飛行表驗收。NOID HiveOS 驗收在同一程序內完成四個 TLS
入口的故障切換並回到主入口。CUDA 13 套件另於 RTX 5090 通過原生自檢與實池
Accepted。本版不發布數值算力聲明。解壓或執行 INVminer 不會安裝或啟用開機
服務、排程、登入項目、cron 或自動重啟規則。
