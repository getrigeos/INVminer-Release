# INVminer v0.1.68

## English

This release adds the qualified NVIDIA A100 (`sm_80`) execution lane while preserving the
existing RTX 20/30/40/50 runtime selection. CUDA 12 packages retain automatic compatibility
fallback for supported older drivers. Pool policy, the 5% NOID developer fee, optional Pass,
and default hardware controls are unchanged.

### Minimal usage

```bash
./invminer --coin noid \
  -o stratum+ssl://eu.innovlab.cc:19601 \
  -u YOUR_NOID_ADDRESS.RIG_NAME
```

The Hong Kong endpoint is `stratum+ssl://hk.innovlab.cc:19601`. `-p/--pass` is optional.
Public binaries enforce the compiled approved TLS endpoint policy.

### Manual upgrade for older HiveOS installations

Only some older HiveOS installations need this manual replacement. Use it only when HiveOS does not update the installed custom miner after the Installation URL is changed to this release.

```bash
miner stop && cd /tmp && rm -rf invminer && rm -f invminer-0.1.68.tar.gz && wget -O invminer-0.1.68.tar.gz https://github.com/getrigeos/INVminer-Release/releases/download/v0.1.68/invminer-0.1.68.tar.gz && tar -xzf invminer-0.1.68.tar.gz && mkdir -p /hive/miners/custom/invminer && rm -f /hive/miners/custom/invminer/invminer && cp -af invminer/. /hive/miners/custom/invminer/ && chmod +x /hive/miners/custom/invminer/invminer /hive/miners/custom/invminer/h-*.sh && /hive/miners/custom/invminer/invminer --version && miner start
```
