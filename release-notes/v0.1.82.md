# INVminer v0.1.82

## GPU command

```bash
./invminer --coin noid -o stratum+ssl://eu.innovlab.cc:19601 -u YOUR_NOID_ADDRESS[.WORKER]
```

## CPU-only command

```bash
./invminer --coin noid --cpu-only -o stratum+ssl://eu.innovlab.cc:19601 -u YOUR_NOID_ADDRESS[.WORKER]
```

## QUAN GPU command

```bash
./invminer --coin quan -o stratum+ssl://eu2.innovlab.cc:17601 -u YOUR_QUANTUS_ADDRESS[.WORKER]
```

`--coin noid` or `--coin quan` is required. A missing or unsupported coin exits
before network or GPU startup. The worker suffix and `--pass` are optional; an
omitted password uses the compatible value `x`.

> **Binary-only risk:** this release may not work with every GPU, CPU, driver,
> OS, or future pool state. Source is not provided, so users cannot independently
> rebuild, audit, or patch it. The software is provided without warranty.

## Changes

- RTX 5090 now uses the qualified native QUAN sparse search and QUIC pipeline.
- NVIDIA CMP 50HX now uses its qualified c2 paired-round carry pipeline.
- Existing RTX 4090, A40, RTX 3080, A100 and generic NVIDIA paths remain in the
  unified executable and keep exact model-based dispatch.
- QUAN user mining accepts compatible QUIC, TCP and TLS endpoints, including
  Quanpool, Kryptex and LuckyPool protocol families. Endpoint hostnames are
  resolved for each connection rather than embedding a resolved pool IP.
- The disclosed QUAN developer fee is 3% and uses a dedicated official Quanpool
  hostname independently of the compatible user pool. NOID remains at 1%.
- Omitting both `--device` and `--devices` starts all visible supported GPUs.
  The process keeps one user-pool connection and assigns disjoint search domains.

## Validation and boundaries

- CUDA 12 and CUDA 13 were each built twice from one frozen source commit in an
  offline pinned container; matching flavors were byte-identical.
- The final CUDA 12 binary passed NOID and QUAN native CPU/GPU self-tests on RTX
  4070. The CMP 50HX native module separately passed its full GPU/CPU exactness
  qualification before release integration.
- This release does not publish a numerical performance claim and does not claim
  a new live-pool acceptance run.
- Linux x86_64 requires glibc 2.30 or newer. Use the CUDA 12 package for broad
  driver compatibility. RTX 50 series requires a Blackwell-capable driver.

## HiveOS flight sheet

- Miner: Custom → `invminer`
- Installation URL: `https://github.com/getrigeos/INVminer-Release/releases/download/v0.1.82/invminer-0.1.82.tar.gz`
- Coin: Custom
- Hash algorithm: leave blank
- NOID Pool URL: `stratum+ssl://eu.innovlab.cc:19601`
- QUAN Pool URL: `stratum+ssl://eu2.innovlab.cc:17601`
- Wallet template: `%WAL%.%WORKER_NAME%`
- Pass: `x`
- Extra config arguments: `--coin noid` for NOID or `--coin quan` for QUAN

All visible GPUs are used automatically; do not add `--devices` unless you want
an explicit subset.

### Foreground troubleshooting

For abnormal startup only: stop the managed miner if present, download into a
new random directory, and show errors in the foreground. Replace the wallet
address and select the intended coin after startup is confirmed.

`(miner stop || true) && cd "$(mktemp -d /tmp/182invminer.XXXXXX)" && wget -O invminer-0.1.82.tar.gz https://github.com/getrigeos/INVminer-Release/releases/download/v0.1.82/invminer-0.1.82.tar.gz && tar -xzf invminer-0.1.82.tar.gz && cd invminer && chmod +x invminer && ./invminer --coin noid --pool stratum+ssl://eu.innovlab.cc:19601 --user YOUR_NOID_ADDRESS --pass x`

### Older HiveOS manual replacement

Only some older HiveOS installations need this manual replacement. Use it only when HiveOS does not update the installed custom miner after the Installation URL is changed to this release.

```bash
miner stop && cd /tmp && rm -rf invminer && rm -f invminer-0.1.82.tar.gz && wget -O invminer-0.1.82.tar.gz https://github.com/getrigeos/INVminer-Release/releases/download/v0.1.82/invminer-0.1.82.tar.gz && tar -xzf invminer-0.1.82.tar.gz && mkdir -p /hive/miners/custom/invminer && rm -f /hive/miners/custom/invminer/invminer && cp -af invminer/. /hive/miners/custom/invminer/ && chmod +x /hive/miners/custom/invminer/invminer /hive/miners/custom/invminer/h-*.sh && /hive/miners/custom/invminer/invminer --version && miner start
```

## 繁體中文

本版整合 RTX 5090 原生 QUAN sparse/QUIC 路徑及 CMP 50HX c2 雙輪管線，並保留
RTX 4090、A40、RTX 3080、A100 與通用 NVIDIA 路徑。QUAN 使用者可連接相容的
QUIC、TCP 或 TLS 礦池；每次連線解析主機名稱，不內嵌礦池解析 IP。

NOID 開發費為有效挖礦時間的 1%，QUAN 為 3%；等待、連線準備失敗或開發費工作
不可用時不計費。解壓或執行 INVminer 不會安裝或啟用開機服務、排程、登入項目、
cron 或自動重啟規則。

### 舊版 HiveOS 手動升級

僅部分舊版 HiveOS 需要此手動覆蓋；只有在更新 Installation URL 後仍未替換已安裝的 Custom Miner 時才執行。

符合上述情況時，執行上方 Older HiveOS manual replacement 的單行命令。
