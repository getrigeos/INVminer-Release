# INVminer v0.1.57

## English

### Highlights

- Updated the reviewed launch profile selected automatically for RTX 4090.
- Retained the reviewed Turing, Ampere, Blackwell, and all embedded device modules
  without changes.
- Retained all native NVIDIA controls introduced in v0.1.55.

This release supports only NOID. The executable remains `invminer`, and the
algorithm must be selected explicitly with `--coin noid`.

> **Binary-only risk:** this release may not work with every GPU, CPU, driver,
> OS, or future pool state. Source is not provided, so users cannot independently
> rebuild, audit, or patch it and must decide whether to trust the executable and
> published checksums. The software is provided without warranty.

### GPU command

```bash
./invminer --coin noid \
  -o stratum+ssl://eu.innovlab.cc:19601 \
  -u YOUR_NOID_ADDRESS.RIG_NAME \
  -p x
```

Use one of the two official NOID TLS endpoints: `eu.innovlab.cc:19601`
(Europe) or `hk.innovlab.cc:19601` (Hong Kong). The examples use Europe;
replace only the hostname to use Hong Kong.

### CPU-only command

```bash
./invminer --coin noid --cpu-only \
  -o stratum+ssl://eu.innovlab.cc:19601 \
  -u YOUR_NOID_ADDRESS.RIG_NAME \
  -p x
```

### Native NVIDIA controls

The miner can apply a power cap, core upper bound, fixed core clock, signed core
offset, and fixed memory clock. A reviewed RTX 4090 power and memory profile can
be expressed without separate `nvidia-smi` commands:

```bash
./invminer --coin noid --devices 0 --power-limit 450 --lock-mem 810 \
  -o stratum+ssl://eu.innovlab.cc:19601 \
  -u YOUR_NOID_ADDRESS.RIG_NAME \
  -p x
```

Each setting is validated against the selected physical GPU. Unsupported values,
missing permissions, or unavailable optional tools produce a warning and mining
continues at the verified original/default state. A partially applied profile
that cannot be rolled back safely stops rather than mining under unknown settings.

### HiveOS

- Miner name: `invminer`
- Installation URL: `https://github.com/getrigeos/INVminer-Release/releases/download/v0.1.57/invminer-0.1.57.tar.gz`
- Hash algorithm: `noid`
- Wallet and worker template: `%WAL%.%WORKER_NAME%`
- Pool URL: `stratum+ssl://eu.innovlab.cc:19601`
- Pass: `x`
- Extra config arguments: leave empty unless ordinary runtime options are needed

The HiveOS archive must remain `<miner-name>-<version>.tar.gz`; do not add the
tag `v`, platform, architecture, HiveOS, or CUDA labels.

#### Manual upgrade for older HiveOS installations

Only some older HiveOS installations need this manual replacement. Use it only when HiveOS does not update the installed custom miner after the Installation URL is changed to this release.

```bash
miner stop && cd /tmp && rm -rf invminer && rm -f invminer-0.1.57.tar.gz && wget -O invminer-0.1.57.tar.gz https://github.com/getrigeos/INVminer-Release/releases/download/v0.1.57/invminer-0.1.57.tar.gz && tar -xzf invminer-0.1.57.tar.gz && mkdir -p /hive/miners/custom/invminer && rm -f /hive/miners/custom/invminer/invminer && cp -af invminer/. /hive/miners/custom/invminer/ && chmod +x /hive/miners/custom/invminer/invminer /hive/miners/custom/invminer/h-*.sh && /hive/miners/custom/invminer/invminer --version && miner start
```

NOID uses a 5% developer fee measured from effective mining time. Waiting,
connection preparation failures, and unavailable fee work are not charged.
Extracting or running the package does not install or enable a boot service,
cron job, scheduled task, login/startup item, or container restart policy.

# INVminer v0.1.57（繁體中文）

### 重點

- 更新 RTX 4090 自動選用的審核啟動設定。
- Turing、Ampere、Blackwell 與所有內嵌裝置模組保持不變。
- 保留 v0.1.55 已加入的全部 NVIDIA 原生控制參數。

本版只支援 NOID，執行檔固定為 `invminer`，並以 `--coin noid` 明確選擇。RTX 4070
已用兩個正式二進位及最終 HiveOS 套件完成驗收；RTX 4090 已用正式 CUDA 13 二進位及
`--power-limit 450 --lock-mem 810` 原生控制完成驗收；RTX 5090 的既有審核路徑保留，
本版未重新實機測試。以上僅代表功能門禁，不是特定型號的效能宣稱。

NOID 僅使用官方 TLS 節點 `eu.innovlab.cc:19601`（歐洲）或
`hk.innovlab.cc:19601`（香港）。上方命令預設展示歐洲節點；使用香港節點時只替換主機名。

不支援的時鐘值、權限不足或可選工具不可用時，程式會告警並以已驗證的原始／預設狀態繼續；
若部分設定無法安全回復，則停止而不會在未知硬體狀態下挖礦。無需另外執行 `nvidia-smi`
即可使用上述功耗及顯存設定。

HiveOS 請使用 `invminer-0.1.57.tar.gz`；Miner name 填 `invminer`、Hash algorithm 填
`noid`、Template 填 `%WAL%.%WORKER_NAME%`、Pass 填 `x`，Extra config arguments 預設
留空。不要改動標準套件名稱，也不要把其他下載位址填入 Extra config arguments。

### 舊版 HiveOS 手動升級

套件不會自行建立或啟用開機服務、cron、排程、登入啟動項或容器重啟策略。本倉庫只提供閉源
