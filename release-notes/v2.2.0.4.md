# INVminer v2.2.0.4

## Changes

- Improve Proxima BLAKE2b-256 search throughput on Blackwell GPUs, verified on RTX 5060 Ti.

## Compatibility

**Proxima upgrade-6 only, 0% developer fee.** NOID/QUAN users should keep their existing package. Keep the existing pool URLs, wallet/worker, clock settings and flight-sheet arguments; change only the installation URL. The optimization is enabled automatically. Kernels for older GPU architectures and the low-CPU waiting behavior of 2.2.0.3 are unchanged. This release does not claim a new RTX 4090 speed gain.

The RTX 5060 Ti comparison ran old → new → old on the same four-card rig, excluding the first 30 seconds of each phase. The old-version windows averaged **3.467 GH/s**, versus **3.926 GH/s** for the new version (**+13.26%** in this measured window). The two old windows were 3.504 and 3.430 GH/s; task gaps and clocks also vary, so the percentage is not a guaranteed kernel-only improvement. The six-card HiveOS runs excluded 25 seconds and totaled **32.896 / 33.067 GH/s**; those are rig totals. Other rows exclude the first 30 seconds. All listed cards submitted Accepted shares. Short samples vary with tasks, clocks, temperatures and transport latency; they do not establish long-term stability, earnings, energy efficiency or performance on untested models. Stale outcomes were retained and excluded from Accepted totals.

## GPU command

```bash
./invminer --coin proxima -o stratum+ssl://global.innovlab.cc:19701 -o stratum+ssl://eu3.innovlab.cc:19701 -u YOUR_PROXIMA_HOLDER_ID.WORKER
```

Use your registered 64-hex holder/account ID. The worker suffix and password are optional; an omitted password uses `x`. All visible supported GPUs are selected by default; use `--devices 0,2` for a subset.

Ordered endpoints, reconnects, primary recovery and `rotate` are retained. Default `primary` mode probes the first endpoint and returns after successful probes. Add `--pool-failover-mode rotate` to remain on a healthy backup until it fails. Mining uses one active Stratum connection, with no separate Python seeker or prox-agent.

## HiveOS flight sheet

- Miner: Custom → `invminer`
- Installation URL: `https://github.com/getrigeos/INVminer-Release/releases/download/v2.2.0.4/invminer-2.2.0.4.tar.gz`
- Coin: Custom / PROX
- Hash algorithm: `proxima`
- Wallet: your registered Proxima holder/account ID
- Wallet template: `%WAL%.%WORKER_NAME%`
- Pool URLs: keep your current ordered endpoints; public examples are `stratum+ssl://global.innovlab.cc:19701` and `stratum+ssl://eu3.innovlab.cc:19701` (one per line, or comma-separated)
- Pass: optional; default `x`
- Extra config arguments: `--coin proxima`

Real HiveOS qualification covered the official custom-miner installer, upgrading from 2.2.0.3, restart, all six GPUs, per-GPU Accepted and statistics. Cloud flight-sheet UI operation was not part of this test.

Linux x86_64 and glibc 2.31+ are required. CUDA 12 needs CUDA Driver API 12.0+; RTX 50-series needs a suitable R570+ driver. CUDA 13 needs Driver API 13.0+ (R580+). Mining TLS stays encrypted without requiring server-certificate verification; download HTTPS verification remains enabled.
