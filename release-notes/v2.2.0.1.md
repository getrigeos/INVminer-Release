# INVminer v2.2.0.1

## Changes

- Add Proxima upgrade-6 BLAKE2b-256 GPU mining as a separate Linux and HiveOS package.

## Compatibility

This package supports **Proxima only**, with **0% developer fee**. NOID/QUAN users should continue using their existing package. The legacy Proxima VRF protocol is incompatible with upgrade-6. Mining kernels are unchanged from the previously distributed 2.2.0.0; the measurements below were repeated using this release's public binaries.

## Tested GPU hashrates / 已测试显卡算力

These are completed nonce attempts divided by elapsed wall time, in **GH/s**, measured with the final public release. Power limits are configured caps, not measured consumption. CUDA 12 is selected by the HiveOS package on these rigs.

| GPU | Cards tested | CUDA | Driver | Power limit per card | Measured window | Per-card hashrate |

| NVIDIA CMP 40HX | 2 | 12 | 580.173.02 | 125 W | 148.88 s | 2.029 / 2.029 GH/s |
| NVIDIA CMP 50HX | 1 | 12 | 580.173.02 | 225 W | 148.88 s | 3.307 GH/s |
| NVIDIA GeForce RTX 5060 Ti | 1 | 12 | 580.173.02 | 180 W | 148.88 s | 3.172 GH/s |
| NVIDIA GeForce RTX 4070 SUPER | 6 | 12 | 535.171.04 | 220 W | 95.31 / 65.31 s | 5.360–5.478 / 5.409–5.540 GH/s |
| NVIDIA GeForce RTX 4090 | 1 | 12 | 580.178.04 | 400 W | 149.69 s | 12.274 GH/s |

The two six-card RTX 4070 SUPER runs totaled **32.392 / 32.762 GH/s**. Those totals are not single-card rates. Each range in the table covers the six individual GPUs in its corresponding run.

The same mixed rig was also tested with the bundled CUDA 13 executable for **88.04 s** after warm-up: CMP 40HX **2.041 / 2.041 GH/s**, CMP 50HX **3.332 GH/s**, RTX 5060 Ti **3.238 GH/s**, at the same power caps and driver. Separate short runs do not establish a general CUDA-flavor performance advantage.

Measurement windows exclude the first 30 seconds on the mixed rig and 25 seconds on the RTX 4070 SUPER/4090 rigs. Existing system clock settings were preserved; the RTX 4090 used 810 MHz memory and a +350 MHz core offset. Short live-pool measurements vary with work availability, clocks and temperature; they are not peak kernel rates, expected earnings or long-term stability claims. Only the listed physical models were qualified for this release. Some runs had stale shares; they were retained and excluded from Accepted counts.

## GPU command

```bash
./invminer --coin proxima -o stratum+ssl://global.innovlab.cc:19701 -o stratum+ssl://eu3.innovlab.cc:19701 -u YOUR_PROXIMA_HOLDER_ID.WORKER
```

Use your registered 64-hex holder/account ID. The worker suffix and password are optional; an omitted password uses `x`. All visible supported GPUs are selected by default; use `--devices 0,2` for a subset.

Ordered endpoints, reconnects, primary recovery and `rotate` are retained. Default `primary` mode probes the first endpoint and returns after successful probes. Add `--pool-failover-mode rotate` to remain on a healthy backup until it fails. Mining uses one active Stratum connection; no separate Python seeker or prox-agent is required.

## HiveOS flight sheet

- Miner: Custom → `invminer`
- Installation URL: `https://github.com/getrigeos/INVminer-Release/releases/download/v2.2.0.1/invminer-2.2.0.1.tar.gz`
- Coin: Custom / PROX
- Hash algorithm: `proxima`
- Wallet: your registered Proxima holder/account ID
- Wallet template: `%WAL%.%WORKER_NAME%`
- Pool URLs, in priority order: `stratum+ssl://global.innovlab.cc:19701`, `stratum+ssl://eu3.innovlab.cc:19701` (one per line, or comma-separated)
- Pass: optional; default `x`
- Extra config arguments: `--coin proxima`

Real HiveOS qualification covered the official custom-miner installer, upgrading from 2.2.0.0, restart, all six GPUs, per-GPU Accepted shares and statistics. Cloud flight-sheet UI operation was not part of this test.

Linux x86_64 and glibc 2.31+ are required. CUDA 12 needs a CUDA Driver API 12.0+ driver; RTX 50-series GPUs need a suitable R570+ driver. CUDA 13 needs Driver API 13.0+ (R580+). Mining TLS remains encrypted without requiring server-certificate verification; download HTTPS verification remains enabled.
