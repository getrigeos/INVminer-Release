# INVminer v0.1.84

## GPU command

```bash
./invminer --coin quan -o stratum+ssl://eu2.innovlab.cc:17601 -u YOUR_QUANTUS_ADDRESS[.WORKER]
```

## CPU-only command

```bash
./invminer --coin noid --cpu-only -o stratum+ssl://eu.innovlab.cc:19601 -u YOUR_NOID_ADDRESS[.WORKER]
```

## NOID GPU command

```bash
./invminer --coin noid -o stratum+ssl://eu.innovlab.cc:19601 -u YOUR_NOID_ADDRESS[.WORKER]
```

`--coin noid` or `--coin quan` is required. The worker suffix and `--pass` are
optional; an omitted password uses the compatible value `x`.

> **Binary-only risk:** this release may not work with every GPU, CPU, driver,
> OS, or future pool state. Source is not provided, so users cannot independently
> rebuild, audit, or patch it. The software is provided without warranty.

## Changes

- RTX 4090 now selects the qualified SM89 Full256 prefix, table, four-kind mining,
  and exact CPU verification path automatically.
- Full256 and Prefix56 jobs keep separate qualified batch geometry. Every GPU
  candidate is reconstructed, hashed again on the CPU, and compared with the
  complete target before submission.
- The qualified CMP 50HX scheduling path is retained. CMP 40HX, A40, RTX 5090
  and other supported NVIDIA paths remain in the unified executable.
- Quanpool, Kryptex, LuckyPool and compatible QUAN QUIC, TCP and TLS pools remain
  selectable. Hostnames are resolved for every connection; provider IP addresses
  are not embedded.
- A HiveOS host-and-port-only Pool URL defaults to authenticated TLS. Plaintext
  requires an explicit `stratum+tcp://` URL.
- The disclosed QUAN developer fee is 2% and uses the official Quanpool hostname.
  NOID remains at 1%.

## Validation and boundaries

- Public and companion CUDA 12 and CUDA 13 binaries were each built twice from
  one frozen source commit in an offline pinned environment. Matching builds and
  archives were byte-identical.
- The exact public CUDA 12/HiveOS artifact passed native QUAN CPU/GPU self-test
  on CMP 50HX and RTX 4090. The packaged HiveOS adapter expanded a host-and-port
  Pool URL to WebPKI TLS, reached Full256 mining, returned valid `h-stats`, and
  submitted an accepted share with zero rejected or stale shares.
- A separate RTX 4090 WebPKI TLS run also submitted an accepted share with zero
  rejected or stale shares.
- This release does not publish a numerical performance claim.
- Linux x86_64 requires glibc 2.30 or newer. Use the CUDA 12 package for broad
  driver compatibility. RTX 50 series requires a Blackwell-capable driver.

## HiveOS flight sheet

- Miner: Custom → `invminer`
- Installation URL: `https://github.com/getrigeos/INVminer-Release/releases/download/v0.1.84/invminer-0.1.84.tar.gz`
- Coin: Custom
- Hash algorithm: `quan` for QUAN or `noid` for NOID
- QUAN Pool URL: `eu2.innovlab.cc:17601` (host-and-port-only defaults to authenticated TLS)
- NOID Pool URL: `eu.innovlab.cc:19601` (host-and-port-only defaults to authenticated TLS)
- Wallet template: `%WAL%.%WORKER_NAME%`
- Pass: `x`
- Extra config arguments: empty by default; add only optional INVminer flags

All visible GPUs are used automatically; do not add `--devices` unless you want
an explicit subset.

### Foreground troubleshooting

For abnormal startup only: stop the managed miner if present, download into a
new random directory, and show errors in the foreground. Replace the wallet
address and select the intended coin after startup is confirmed.

`(miner stop || true) && cd "$(mktemp -d /tmp/184invminer.XXXXXX)" && wget -O invminer-0.1.84.tar.gz https://github.com/getrigeos/INVminer-Release/releases/download/v0.1.84/invminer-0.1.84.tar.gz && tar -xzf invminer-0.1.84.tar.gz && cd invminer && chmod +x invminer && ./invminer --coin noid --pool stratum+ssl://eu.innovlab.cc:19601 --user YOUR_NOID_ADDRESS --pass x`

### Older HiveOS manual replacement

Only some older HiveOS installations need this manual replacement. Use it only when HiveOS does not update the installed custom miner after the Installation URL is changed to this release.

```bash
miner stop && cd /tmp && rm -rf invminer && rm -f invminer-0.1.84.tar.gz && wget -O invminer-0.1.84.tar.gz https://github.com/getrigeos/INVminer-Release/releases/download/v0.1.84/invminer-0.1.84.tar.gz && tar -xzf invminer-0.1.84.tar.gz && mkdir -p /hive/miners/custom/invminer && rm -f /hive/miners/custom/invminer/invminer && cp -af invminer/. /hive/miners/custom/invminer/ && chmod +x /hive/miners/custom/invminer/invminer /hive/miners/custom/invminer/h-*.sh && /hive/miners/custom/invminer/invminer --version && miner start
```

## 繁體中文

v0.1.84 讓 RTX 4090 自動選擇已驗收的 Full256 路徑，保留 CMP 50HX、CMP 40HX、
A40、RTX 5090 及相容的 QUAN 礦池協議。每個 GPU 候選都會在 CPU 端重建並用完整
目標複核。QUAN 開發費調整為 2%，費率通道使用官方 Quanpool 主機名稱。

HiveOS 的主機加連接埠 Pool URL 預設使用驗證式 TLS；只有明確填寫
`stratum+tcp://` 才使用明文。正式 CUDA 12/HiveOS 制品已在 CMP 50HX 通過飛行表、
WebPKI TLS、Accepted 且零 Rejected/Stale，以及 `h-stats` 驗收。本版不發布數值算力聲明。
解壓或執行 INVminer 不會安裝或啟用開機服務、排程、登入項目、cron 或自動重啟規則。

### 舊版 HiveOS 手動升級

僅部分舊版 HiveOS 需要此手動覆蓋；只有在更新 Installation URL 後仍未替換已安裝的 Custom Miner 時才執行。

符合上述情況時，執行上方 Older HiveOS manual replacement 的單行命令。
