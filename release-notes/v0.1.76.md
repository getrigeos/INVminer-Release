# INVminer v0.1.76

## GPU command

```bash
./invminer --coin noid -o stratum+ssl://eu.innovlab.cc:19601 -u YOUR_NOID_ADDRESS
```

## CPU-only command

```bash
./invminer --coin noid --cpu-only -o stratum+ssl://eu.innovlab.cc:19601 -u YOUR_NOID_ADDRESS
```

The worker suffix and `--pass` are optional. Replace the hostname with
`hk.innovlab.cc:19601` for Hong Kong. Pool information: <https://noid.innovlab.cc/>.

## Fixes

- NOID: an isolated missing share response no longer disconnects a session when
  a later submission has already been accepted. Sustained response loss still
  triggers automatic reconnection.
- Late responses are retained for up to 120 seconds and settled by their actual
  result. Timeouts are not reported as accepted, rejected, or stale.
- One stale response no longer incorrectly marks other pending shares stale.

Mining kernels, default hardware settings, and the NOID developer fee are unchanged.
The fee is 1% of effective mining time; waiting and unavailable fee work are not charged.
Known display issue: a legacy startup line still says 5%; the active NOID schedule
and `--build-info` policy remain 1%.
Public binaries retain the compiled approved TLS endpoint policy, certificate-chain
and hostname verification. They reject plaintext, insecure TLS, and custom pins.

## Compatibility and qualification

Linux x86_64, glibc 2.30+. CUDA 12/HiveOS requires driver 535+ for pre-Blackwell
cards; RTX 50 requires driver 580+. CUDA 13 requires driver 580+.

| GPU family | Package | This release's physical test |
|---|---|---|
| CMP 40HX/50HX, RTX 20 (SM75) | CUDA 12 / HiveOS | Not retested |
| A100 / 170HX (SM80) | CUDA 12 / HiveOS, or CUDA 13 | Not retested |
| RTX 30 (SM86) | CUDA 12 / HiveOS, or CUDA 13 | Not retested |
| RTX 40 (SM89) | CUDA 12 / HiveOS, or CUDA 13 | RTX 4070, driver 580.178.04, default controls |
| RTX 50 (SM120) | CUDA 12 / HiveOS, or CUDA 13; driver 580+ | Not retested |

Every row uses the GPU command above, without device or tuning arguments.
Final RTX 4070 binaries passed CPU/GPU correctness and accepted-share checks.
The HiveOS package passed four-pool failure/recovery and returned to the primary
in the same process. Backup pools do not maintain permanent mining sessions.

Short tests are not a long-duration or multi-GPU guarantee. A client cannot recover
requests already discarded by a server; pool-side problems still require pool fixes.
Binary-only software is provided without warranty: users cannot independently
rebuild, audit, or patch it. Extracting/running it does not install a startup service,
scheduled task, login item, cron job, or restart policy.

### Foreground troubleshooting

For abnormal startup only: stop the managed miner if present, download into a new
random directory, and show errors in the foreground. Replace the wallet address.

`(miner stop || true) && cd "$(mktemp -d /tmp/176invminer.XXXXXX)" && wget -O invminer-0.1.76.tar.gz https://github.com/getrigeos/INVminer-Release/releases/download/v0.1.76/invminer-0.1.76.tar.gz && tar -xzf invminer-0.1.76.tar.gz && cd invminer && chmod +x invminer && ./invminer --coin noid --pool stratum+ssl://eu.innovlab.cc:19601 --user YOUR_NOID_ADDRESS --pass x`

### Older HiveOS manual replacement

Only some older HiveOS installations need this manual replacement. Use it only when HiveOS does not update the installed custom miner after the Installation URL is changed to this release.

```bash
miner stop && cd /tmp && rm -rf invminer && rm -f invminer-0.1.76.tar.gz && wget -O invminer-0.1.76.tar.gz https://github.com/getrigeos/INVminer-Release/releases/download/v0.1.76/invminer-0.1.76.tar.gz && tar -xzf invminer-0.1.76.tar.gz && mkdir -p /hive/miners/custom/invminer && rm -f /hive/miners/custom/invminer/invminer && cp -af invminer/. /hive/miners/custom/invminer/ && chmod +x /hive/miners/custom/invminer/invminer /hive/miners/custom/invminer/h-*.sh && /hive/miners/custom/invminer/invminer --version && miner start
```

### 修復

- NOID：較新的提交已被接受時，單條回執缺失不再誤斷健康連線；持續收不到回執仍會自動重連。
- 遲到回執最多保留 120 秒，依實際結果逐條結算；超時不偽記為 accepted、rejected 或 stale。
- 單條 stale 回執不再錯誤地將其他待確認份額一起標記為 stale。

挖礦核心、預設硬體設定及 NOID 開發費均不變。費率為有效挖礦時間的 1%，等待及開發費工作
不可用時間不計費。公開版保留編譯期批准的 TLS 端點策略、憑證鏈與主機名稱校驗，拒絕明文、
不安全 TLS 與自訂憑證 pin。
已知顯示問題：一行舊啟動資訊仍顯示 5%，但實際 NOID 排程與 `--build-info` 策略均為 1%。

### 相容性與驗證

Linux x86_64、glibc 2.30+。CUDA 12／HiveOS 的非 Blackwell 顯卡需要 535+ 驅動，
RTX 50 需要 580+；CUDA 13 全部需要 580+。

| 顯卡系列 | 安裝包 | 本版實機驗證 |
|---|---|---|
| CMP 40HX/50HX、RTX 20（SM75） | CUDA 12／HiveOS | 未重測 |
| A100／170HX（SM80） | CUDA 12／HiveOS 或 CUDA 13 | 未重測 |
| RTX 30（SM86） | CUDA 12／HiveOS 或 CUDA 13 | 未重測 |
| RTX 40（SM89） | CUDA 12／HiveOS 或 CUDA 13 | RTX 4070、580.178.04 驅動、預設設定 |
| RTX 50（SM120） | CUDA 12／HiveOS 或 CUDA 13；580+ 驅動 | 未重測 |

各列均使用上方 GPU 命令，不加顯卡選擇或調優參數。RTX 4070 最終二進位通過 CPU/GPU 正確性與
accepted 份額檢查；HiveOS 包通過四池故障恢復，並於同一程序返回主池，不長期維持備用挖礦連線。

短測不保證長時間或多卡結果。客戶端無法恢復伺服器已丟棄的請求，池端問題仍須由礦池修復。
本軟體僅提供二進位且不附保證，使用者無法自行重建、稽核或修補；解壓或執行不會安裝開機服務、
排程、登入項目、cron 或自動重啟策略。
