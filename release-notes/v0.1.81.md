# INVminer v0.1.81

## GPU command

```bash
./invminer --coin noid -o stratum+ssl://eu.innovlab.cc:19601 -u YOUR_NOID_ADDRESS[.WORKER]
```

## CPU-only command

```bash
./invminer --coin noid --cpu-only -o stratum+ssl://eu.innovlab.cc:19601 -u YOUR_NOID_ADDRESS[.WORKER]
```

## QUAN GPU command

```bash
./invminer --coin quan -o stratum+ssl://eu2.innovlab.cc:17601 -u YOUR_QUANTUS_ADDRESS[.WORKER]
```

`--coin noid` or `--coin quan` is required. A missing or unsupported coin exits
before network or GPU startup. The worker suffix and `--pass` are optional; an
omitted password uses the compatible value `x`.

> **Binary-only risk:** this release may not work with every GPU, CPU, driver,
> OS, or future pool state. Source is not provided, so users cannot independently
> rebuild, audit, or patch it. The software is provided without warranty.

## Changes

- NVIDIA A40 now selects a dedicated QUAN native module and launch profile. The
  existing generic `sm_86` path remains available for RTX 30 models.
- Omitting both `--device` and `--devices` now starts all visible supported GPUs.
  One process keeps one user-pool connection and assigns disjoint search domains
  to every GPU. Explicit `--device` and `--devices` selection remains available.
- The same executable and HiveOS archive support NOID and QUAN. NOID retains its
  current implementation and native paths.
- CUDA 12 and CUDA 13 were each rebuilt twice from the same frozen source in
  empty outputs, with byte-identical results. The release boundary and archive
  contents passed the public package checks.

## Qualification and boundaries

- The final CUDA 12 package passed native CPU/GPU self-tests and live accepted
  shares for both NOID and QUAN on RTX 4070. Its packaged `h-config.sh`,
  `h-run.sh`, and `h-stats.sh` path passed for both coins.
- The final CUDA 13 binary selected the dedicated NVIDIA A40 module and passed
  its complete CPU/GPU exact self-test. This release does not publish a numerical
  performance claim.
- The shared runtime passed one-, two-, and eight-worker allocation tests. Eight
  QUAN workers used one user TCP session and non-overlapping work ranges. A
  physical six-GPU qualification host was unavailable during final release
  validation, so that physical configuration is not claimed as tested here.
- Linux x86_64 requires glibc 2.30 or newer. For NOID, CUDA 12 supports Driver
  535+ on pre-Blackwell GPUs; RTX 50 requires a Blackwell-capable 580+ driver.
  Qualified QUAN `sm_75`, `sm_86`, and `sm_120` lanes require driver 580.65.06+
  and its `sm_89` lane requires driver 595.84+.

### Foreground troubleshooting

For abnormal startup only: stop the managed miner if present, download into a
new random directory, and show errors in the foreground. Replace the wallet
address and select the intended coin after startup is confirmed.

`(miner stop || true) && cd "$(mktemp -d /tmp/181invminer.XXXXXX)" && wget -O invminer-0.1.81.tar.gz https://github.com/getrigeos/INVminer-Release/releases/download/v0.1.81/invminer-0.1.81.tar.gz && tar -xzf invminer-0.1.81.tar.gz && cd invminer && chmod +x invminer && ./invminer --coin noid --pool stratum+ssl://eu.innovlab.cc:19601 --user YOUR_NOID_ADDRESS --pass x`

### Older HiveOS manual replacement

Only some older HiveOS installations need this manual replacement. Use it only when HiveOS does not update the installed custom miner after the Installation URL is changed to this release.

```bash
miner stop && cd /tmp && rm -rf invminer && rm -f invminer-0.1.81.tar.gz && wget -O invminer-0.1.81.tar.gz https://github.com/getrigeos/INVminer-Release/releases/download/v0.1.81/invminer-0.1.81.tar.gz && tar -xzf invminer-0.1.81.tar.gz && mkdir -p /hive/miners/custom/invminer && rm -f /hive/miners/custom/invminer/invminer && cp -af invminer/. /hive/miners/custom/invminer/ && chmod +x /hive/miners/custom/invminer/invminer /hive/miners/custom/invminer/h-*.sh && /hive/miners/custom/invminer/invminer --version && miner start
```

## 繁體中文

### GPU 啟動

```bash
./invminer --coin noid -o stratum+ssl://eu.innovlab.cc:19601 -u YOUR_NOID_ADDRESS[.WORKER]
```

### 僅 CPU

```bash
./invminer --coin noid --cpu-only -o stratum+ssl://eu.innovlab.cc:19601 -u YOUR_NOID_ADDRESS[.WORKER]
```

### QUAN GPU 啟動

```bash
./invminer --coin quan -o stratum+ssl://eu2.innovlab.cc:17601 -u YOUR_QUANTUS_ADDRESS[.WORKER]
```

必須明確使用 `--coin noid` 或 `--coin quan`；未指定或指定其他幣種時，
INVminer 會在聯網及啟動 GPU 前退出。worker 後綴與 `--pass` 可省略。

### 本版變更

- NVIDIA A40 現會精確選用 QUAN 專用原生模組及啟動設定；RTX 30 型號原有的
  通用 `sm_86` 路徑保持不變。
- 未提供 `--device` 或 `--devices` 時，預設啟動全部可見且支援的 GPU。
  所有 GPU 共用一條使用者礦池連線，並取得互不重疊的搜尋區間；仍可明確選擇單卡或子集。
- 同一個執行檔及 HiveOS 安裝包同時支援 NOID 與 QUAN；NOID 保留原有實作及原生路徑。
- CUDA 12 與 CUDA 13 均從凍結源碼及空輸出目錄各重建兩次，結果逐位元一致。

### 驗證與邊界

- 最終 CUDA 12 包已在 RTX 4070 完成兩個幣種的原生 CPU/GPU 自檢及真池 accepted；
  NOID 與 QUAN 均通過 HiveOS `h-config.sh` → `h-run.sh` → `h-stats.sh` 路徑。
- 最終 CUDA 13 二進位在 NVIDIA A40 精確選用專用模組並通過完整 CPU/GPU 自檢。
  本版不公開數值效能聲明。
- 共用 runtime 已通過 1、2、8 worker 配置；8 個 QUAN worker 只建立 1 條使用者 TCP session，
  搜尋範圍不重疊。最終發布時六卡實機入口不可用，因此不宣稱該實機配置已完成測試。
- Linux x86_64 需要 glibc 2.30 或更新版本。NOID 的 CUDA 12 在 Blackwell 以前 GPU 支援
  Driver 535+；RTX 50 需要支援 Blackwell 的 Driver 580+。QUAN 已驗收的 `sm_75`、`sm_86`、
  `sm_120` 路徑需要 Driver 580.65.06+，`sm_89` 需要 Driver 595.84+。
