# INVminer v0.1.78

## GPU command

```bash
./invminer --coin noid -o stratum+ssl://eu.innovlab.cc:19601 -u YOUR_NOID_ADDRESS
```

## CPU-only command

```bash
./invminer --coin noid --cpu-only -o stratum+ssl://eu.innovlab.cc:19601 -u YOUR_NOID_ADDRESS
```

The worker suffix and `--pass` are optional. Replace the hostname with
`hk.innovlab.cc:19601` for Hong Kong. Pool information: <https://noid.innovlab.cc/>.

## Changes

- Desktop RTX 4070 and RTX 4090: the updated NOID profile is now included and selected automatically on supported drivers (580+).
- RTX 5090: retains the optimization already shipped in v0.1.77; no additional performance gain is claimed in this version.
- Optional `--noid-legacy-profile` retains the previous compute profile. This is a compute choice, not an overclock; it is useful when lower board power matters more than maximum throughput on RTX 4070. Other GPU models retain their existing kernels.

### Same-card version comparison

Default hardware only: RTX 4070 200 W / driver 580.178.04; RTX 4090 450 W /
driver 595.71.05; RTX 5090 575 W / driver 595.91.07. No clock offsets or locks.
Rates use complete 60-second work windows after warm-up; efficiency is completed
work divided by board joules measured in the same window, not wall-socket power.
The v0.1.77 columns are same-day retested controls. The v0.1.78 columns use the
later final public CUDA 12 repeat, not the highest first run. These sequential
windows are not a simultaneous or randomized ABBA trial.

| GPU | v0.1.77 MH/s / W | v0.1.78 MH/s / W | Hashrate change | Work/J change |
|---|---:|---:|---:|---:|
| RTX 4070 | 57.610 / 171.22 | 65.444 / 196.87 | +13.60% | -1.20% |
| RTX 4090 | 158.563 / 442.60 | 174.099 / 443.16 | +9.80% | +9.66% |
| RTX 5090 | 236.786 / 568.34 | 237.360 / 569.06 | +0.24% | +0.11% |

RTX 4070 favors throughput at higher board power; it is not a default-efficiency
improvement. With `--noid-legacy-profile`, the final build measured 57.521 MH/s at
170.62 W (0.3371 MHash/J). RTX 5090 retains its existing optimization; the small
window difference is not evidence of another gain over v0.1.77. No OC results
or untested GPU models are extrapolated.

### Fl4shMiner 1.3.8 comparison

Same cards and default hardware controls; every cell is **MH/s / board W / MHash/J**.
Vendor controls are retained complete-work windows from the same test day;
this is not a pool payout or long-term share-quality comparison.

| GPU | INVminer v0.1.78 default | Fl4shMiner 1.3.8 default | Fl4shMiner 1.3.8 efficiency mode |
|---|---:|---:|---:|
| RTX 4070 | 65.444 / 196.87 / 0.3324 | 65.434 / 199.23 / 0.3284 | 57.973 / 164.58 / 0.3523 |
| RTX 4090 | 174.099 / 443.16 / 0.3929 | 173.470 / 450.36 / 0.3852 | 161.501 / 448.61 / 0.3600 |
| RTX 5090 | 237.360 / 569.06 / 0.4171 | 235.325 / 574.99 / 0.4093 | N/A |

The default speed margins are small and do not establish a reliable 5% lead.
Fl4shMiner's efficiency mode still has the better work/J result on this RTX 4070
sample. Its efficiency mode is unavailable for RTX 5090 in this version.
[Competitor release](https://github.com/Fl4sh9174/Fl4shMiner/releases/tag/v1.3.8).

Default hardware controls are unchanged. The NOID developer fee remains 1% of
effective mining time; waiting and unavailable fee work are not charged.
Public binaries retain the compiled approved TLS endpoint policy, certificate-chain
and hostname verification. They reject plaintext, insecure TLS, and custom pins.

## Compatibility and qualification

Linux x86_64, glibc 2.30+. CUDA 12/HiveOS requires driver 535+ for pre-Blackwell
cards; RTX 50 requires driver 580+. CUDA 13 requires driver 580+.

| GPU family | Package | This release's physical test |
|---|---|---|
| CMP 40HX/50HX, RTX 20 (SM75) | CUDA 12 / HiveOS | Not retested |
| A100 / 170HX (SM80) | CUDA 12 / HiveOS, or CUDA 13 | Not retested |
| RTX 30 (SM86) | CUDA 12 / HiveOS, or CUDA 13 | Not retested |
| RTX 40 (SM89) | CUDA 12 / HiveOS, or CUDA 13 | RTX 4070 / RTX 4090, drivers 580.178.04 / 595.71.05, default controls |
| RTX 50 (SM120) | CUDA 12 / HiveOS, or CUDA 13; driver 580+ | Desktop RTX 5090, driver 595.91.07, default controls |

Every row uses the GPU command above, without device or tuning arguments.
Final desktop RTX 4070, RTX 4090 and RTX 5090 binaries passed CPU/GPU correctness and accepted-share checks.
The HiveOS package passed four-pool failure/recovery and returned to the primary
in the same process. Backup pools do not maintain permanent mining sessions.
Shared-IP endpoints were isolated only inside the fault-test harness with end-to-end
TLS preserved; separate unproxied endpoint checks also passed. This tests logical
endpoint recovery, not independent failures of a shared backend.
One initial TLS connection attempt failed and then recovered automatically;
established-session reconnect counters remained zero in the direct checks.
This release does not change the transport code. Nonzero stale shares are recorded
where observed; the short checks do not establish a long-term reject-rate advantage.

Short tests are not a long-duration or multi-GPU guarantee. A client cannot recover
requests already discarded by a server; pool-side problems still require pool fixes.
Binary-only software is provided without warranty: users cannot independently
rebuild, audit, or patch it. Extracting/running it does not install a startup service,
scheduled task, login item, cron job, or restart policy.

### Foreground troubleshooting

For abnormal startup only: stop the managed miner if present, download into a new
random directory, and show errors in the foreground. Replace the wallet address.

`(miner stop || true) && cd "$(mktemp -d /tmp/178invminer.XXXXXX)" && wget -O invminer-0.1.78.tar.gz https://github.com/getrigeos/INVminer-Release/releases/download/v0.1.78/invminer-0.1.78.tar.gz && tar -xzf invminer-0.1.78.tar.gz && cd invminer && chmod +x invminer && ./invminer --coin noid --pool stratum+ssl://eu.innovlab.cc:19601 --user YOUR_NOID_ADDRESS --pass x`

### Older HiveOS manual replacement

Only some older HiveOS installations need this manual replacement. Use it only when HiveOS does not update the installed custom miner after the Installation URL is changed to this release.

```bash
miner stop && cd /tmp && rm -rf invminer && rm -f invminer-0.1.78.tar.gz && wget -O invminer-0.1.78.tar.gz https://github.com/getrigeos/INVminer-Release/releases/download/v0.1.78/invminer-0.1.78.tar.gz && tar -xzf invminer-0.1.78.tar.gz && mkdir -p /hive/miners/custom/invminer && rm -f /hive/miners/custom/invminer/invminer && cp -af invminer/. /hive/miners/custom/invminer/ && chmod +x /hive/miners/custom/invminer/invminer /hive/miners/custom/invminer/h-*.sh && /hive/miners/custom/invminer/invminer --version && miner start
```

### 變更

- 桌面 RTX 4070 與 RTX 4090：新版 NOID 計算設定已正式包含於安裝包，在支援的驅動（580+）自動選用。
- RTX 5090：保留 v0.1.77 已發布的優化；本版不宣稱額外效能提升。
- 可選 `--noid-legacy-profile` 保留上一版計算設定，並非超頻；RTX 4070 若重視較低板卡功耗而非最高吞吐量，可選此設定。其他型號保留原有核心。

### 同卡版本對照

全部使用預設硬體設定：RTX 4070 功耗牆 200 W／驅動 580.178.04；RTX 4090
450 W／595.71.05；RTX 5090 575 W／595.91.07。核心與顯存偏移為 0，未鎖頻。
預熱後量測完整 60 秒工作窗口；能效為完成工作量除以同窗板卡焦耳，並非插座功耗。
v0.1.77 欄為同日重測控制組；v0.1.78 欄採最終公開 CUDA 12 稍後複測，
不是首次最高值。這些是先後測試窗口，不是同時或隨機交替 ABBA 試驗。

| 顯卡 | v0.1.77 MH/s／W | v0.1.78 MH/s／W | 算力變化 | 每焦耳工作量變化 |
|---|---:|---:|---:|---:|
| RTX 4070 | 57.610 / 171.22 | 65.444 / 196.87 | +13.60% | -1.20% |
| RTX 4090 | 158.563 / 442.60 | 174.099 / 443.16 | +9.80% | +9.66% |
| RTX 5090 | 236.786 / 568.34 | 237.360 / 569.06 | +0.24% | +0.11% |

RTX 4070 以較高功耗換取較高算力，不能稱為預設能效提升；選用 `--noid-legacy-profile`
時，最終包測得 57.521 MH/s、170.62 W、0.3371 MHash/J。RTX 5090 保留原有優化，
微小窗口差異不是較 v0.1.77 再次提升的證據。本輪不外推超頻或未測型號。

### 相容性與驗證

Linux x86_64、glibc 2.30+。CUDA 12／HiveOS 的非 Blackwell 顯卡需要 535+ 驅動，
RTX 50 需要 580+；CUDA 13 全部需要 580+。

| 顯卡系列 | 安裝包 | 本版實機驗證 |
|---|---|---|
| CMP 40HX/50HX、RTX 20（SM75） | CUDA 12／HiveOS | 未重測 |
| A100／170HX（SM80） | CUDA 12／HiveOS 或 CUDA 13 | 未重測 |
| RTX 30（SM86） | CUDA 12／HiveOS 或 CUDA 13 | 未重測 |
| RTX 40（SM89） | CUDA 12／HiveOS 或 CUDA 13 | RTX 4070／RTX 4090、580.178.04／595.71.05 驅動、預設設定 |
| RTX 50（SM120） | CUDA 12／HiveOS 或 CUDA 13；580+ 驅動 | 桌面 RTX 5090、595.91.07 驅動、預設設定 |

各列均使用上方 GPU 命令，不加顯卡選擇或調優參數。桌面 RTX 4070、RTX 4090 與 RTX 5090 最終二進位通過 CPU/GPU 正確性與
accepted 份額檢查；HiveOS 包通過四池故障恢復，並於同一程序返回主池，不長期維持備用挖礦連線。
共享 IP 端點僅於故障測試工具內隔離，保留端到端 TLS，另通過不經代理的直接端點檢查；
這證明邏輯端點恢復，不代表共享後端的獨立故障測試。
一次初始 TLS 連線失敗後自動恢復；直接測試中的已建立會話重連計數仍為 0。
本版不改傳輸程式碼；如實記錄觀測到的非零 stale，短測不能證明長期拒絕率優勢。

短測不保證長時間或多卡結果。客戶端無法恢復伺服器已丟棄的請求，池端問題仍須由礦池修復。
本軟體僅提供二進位且不附保證，使用者無法自行重建、稽核或修補；解壓或執行不會安裝開機服務、
排程、登入項目、cron 或自動重啟策略。
