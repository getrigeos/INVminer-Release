# INVminer v0.1.55

## GPU command

```bash
./invminer --coin noid \
  -o stratum+ssl://stratum.innovlab.cc:19601 \
  -u YOUR_NOID_ADDRESS.RIG_NAME \
  -p x
```

## CPU-only command

```bash
./invminer --coin noid --cpu-only \
  -o stratum+ssl://stratum.innovlab.cc:19601 \
  -u YOUR_NOID_ADDRESS.RIG_NAME \
  -p x
```

This release supports only NOID. The executable remains `invminer`, and the
algorithm must be selected explicitly with `--coin noid`.

> **Binary-only risk:** this release may not work with every GPU, CPU, driver,
> OS, or future pool state. Source is not provided, so users cannot independently
> rebuild, audit, or patch it and must decide whether to trust the executable and
> published checksums. The software is provided without warranty.

## Native NVIDIA controls

v0.1.55 adds complete NVIDIA control forwarding to the unified NOID entry. The
miner can apply a power cap, core upper bound, fixed core clock, signed core
offset, and fixed memory clock. Core-offset operation also supports an explicit
X display and Xauthority path. The fixed-core and core-upper-bound modes are
mutually exclusive.

The equivalent of a 450 W power cap and an 810 MHz fixed memory clock is:

```bash
./invminer --coin noid --devices 0 --power-limit 450 --lock-mem 810 \
  -o stratum+ssl://stratum.innovlab.cc:19601 \
  -u YOUR_NOID_ADDRESS.RIG_NAME \
  -p x
```

Each setting is validated against the selected physical GPU. Unsupported
values, missing permissions, or unavailable optional tools produce a warning
and mining continues at the verified original/default state. A partially
applied profile that cannot be rolled back safely stops rather than mining
under unknown settings.

## HiveOS

- Miner name: `invminer`
- Installation URL: `https://github.com/getrigeos/INVminer-Release/releases/download/v0.1.55/invminer-0.1.55.tar.gz`
- Hash algorithm: `noid`
- Wallet and worker template: `%WAL%.%WORKER_NAME%`
- Pool URL: `stratum+ssl://stratum.innovlab.cc:19601`
- Pass: `x`
- Extra config arguments: leave empty unless ordinary runtime options are needed

The HiveOS archive must remain `<miner-name>-<version>.tar.gz`; do not add the
tag `v`, platform, architecture, HiveOS, or CUDA labels. Do not place an
alternate package URL in Extra config arguments.

### Manual upgrade for older HiveOS installations

Only some older HiveOS installations need this manual replacement. Use it only when HiveOS does not update the installed custom miner after the Installation URL is changed to this release.

```bash
miner stop && cd /tmp && rm -rf invminer && rm -f invminer-0.1.55.tar.gz && wget -O invminer-0.1.55.tar.gz https://github.com/getrigeos/INVminer-Release/releases/download/v0.1.55/invminer-0.1.55.tar.gz && tar -xzf invminer-0.1.55.tar.gz && mkdir -p /hive/miners/custom/invminer && rm -f /hive/miners/custom/invminer/invminer && cp -af invminer/. /hive/miners/custom/invminer/ && chmod +x /hive/miners/custom/invminer/invminer /hive/miners/custom/invminer/h-*.sh && /hive/miners/custom/invminer/invminer --version && miner start
```

With no device list, supported GPUs share one user-pool connection and use
non-overlapping search ranges. Normal operation does not require geometry,
thread, batch, ISA, clock, or `--state-dir` arguments.

NOID uses a 5% developer fee measured from effective mining time. Waiting,
connection preparation failures, and unavailable fee work are not charged.
The payout identity is not printed in normal logs or public documentation.

Extracting or running the package does not install or enable a boot service,
cron job, scheduled task, login/startup item, or container restart policy.
