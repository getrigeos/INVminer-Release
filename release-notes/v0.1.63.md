# INVminer v0.1.63

## NOID pool

Pool website: <https://noid.innovlab.cc/>

```bash
./invminer --coin noid \
  -o stratum+ssl://eu.innovlab.cc:19601 \
  -u YOUR_NOID_ADDRESS.RIG_NAME
```

`-p/--pass` is optional. The Hong Kong endpoint is
`stratum+ssl://hk.innovlab.cc:19601`.

## Tested GPU profiles

Public v0.1.63 assets, one physical card, warm 60-second runs:

| GPU | Package / environment | Power cap | Memory lock | Core offset | 60-second rate |
|---|---|---:|---:|---:|---:|
| RTX 3080 10GB | HiveOS/CUDA 12; INVminer controls | 320 W | 810 MHz | +260 MHz | 64.386 MH/s |
| RTX 4090 | HiveOS/CUDA 12; default clocks | 450 W | Default | 0 | 148.972 MH/s |
| RTX 4090 | CUDA 13; operating-system tuning | 450 W | 810 MHz | +250 MHz | 161.447 MH/s |
| RTX 5090 | CUDA 13; default clocks | 575 W | Default | 0 | 192.195 MH/s |
| RTX 5090 | CUDA 13; operating-system tuning | 575 W | 810 MHz | +250 MHz | 204.917 MH/s |

These are sample-card results, not guarantees. Start with a lower offset and
increase only after checking temperature, accepted work, and stability.

### RTX 3080: INVminer-managed profile

```bash
./invminer --coin noid \
  --power-limit 320 \
  --lock-mem 810 \
  --core-clock-offset 260 \
  --nvidia-display :0 \
  --nvidia-xauthority /path/to/Xauthority \
  -o stratum+ssl://eu.innovlab.cc:19601 \
  -u YOUR_NOID_ADDRESS.RIG_NAME
```

### RTX 4090 / RTX 5090: operating-system profile

Use the power cap listed for the exact GPU row. The tested miner command itself
contains no INVminer tuning option:

```bash
sudo nvidia-smi -i 0 -pl POWER_W
sudo nvidia-smi -i 0 -lmc 810,810
sudo env DISPLAY=:0 XAUTHORITY=/path/to/Xauthority \
  nvidia-settings -a '[gpu:0]/GPUGraphicsClockOffsetAllPerformanceLevels=250'

./invminer --coin noid \
  -o stratum+ssl://eu.innovlab.cc:19601 \
  -u YOUR_NOID_ADDRESS.RIG_NAME
```

External settings are not restored by INVminer. Restore them when mining stops:

```bash
sudo nvidia-smi -i 0 -rgc
sudo nvidia-smi -i 0 -rmc
sudo env DISPLAY=:0 XAUTHORITY=/path/to/Xauthority \
  nvidia-settings -a '[gpu:0]/GPUGraphicsClockOffsetAllPerformanceLevels=0'
```

## 顯卡實測設定

以下均使用公開 v0.1.63 資產、單張實體顯卡與熱卡 60 秒測試：

| GPU | 套件／環境 | 功率牆 | 顯存鎖定 | 核心 offset | 60 秒算力 |
|---|---|---:|---:|---:|---:|
| RTX 3080 10GB | HiveOS／CUDA 12；INVminer 控制 | 320 W | 810 MHz | +260 MHz | 64.386 MH/s |
| RTX 4090 | HiveOS／CUDA 12；預設頻率 | 450 W | 預設 | 0 | 148.972 MH/s |
| RTX 4090 | CUDA 13；作業系統調優 | 450 W | 810 MHz | +250 MHz | 161.447 MH/s |
| RTX 5090 | CUDA 13；預設頻率 | 575 W | 預設 | 0 | 192.195 MH/s |
| RTX 5090 | CUDA 13；作業系統調優 | 575 W | 810 MHz | +250 MHz | 204.917 MH/s |

結果只代表實測樣卡，不保證每張卡均相同。請從更低的核心 offset 開始，確認溫度、accepted 工作與
穩定性後再逐步提高。RTX 3080 使用上方 INVminer 原生參數；RTX 4090／5090 使用上方系統設定，
其中 `POWER_W` 分別替換為 `450`／`575`。外部設定不會由 INVminer 自動還原，停止後請執行還原命令。

## Manual upgrade for older HiveOS installations

Only some older HiveOS installations need this manual replacement. Use it only when HiveOS does not update the installed custom miner after the Installation URL is changed to this release.

```bash
miner stop && cd /tmp && rm -rf invminer && rm -f invminer-0.1.63.tar.gz && wget -O invminer-0.1.63.tar.gz https://github.com/getrigeos/INVminer-Release/releases/download/v0.1.63/invminer-0.1.63.tar.gz && tar -xzf invminer-0.1.63.tar.gz && mkdir -p /hive/miners/custom/invminer && rm -f /hive/miners/custom/invminer/invminer && cp -af invminer/. /hive/miners/custom/invminer/ && chmod +x /hive/miners/custom/invminer/invminer /hive/miners/custom/invminer/h-*.sh && /hive/miners/custom/invminer/invminer --version && miner start
```

### 舊版 HiveOS 手動升級

僅部分舊版 HiveOS 需要此手動覆蓋；只有在更新 Installation URL 後仍未替換已安裝的 Custom Miner 時才執行。
