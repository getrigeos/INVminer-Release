# INVminer v0.1.51

## GPU command

```bash
./invminer --coin noid \
  -o stratum+ssl://stratum.innovlab.cc:19601 \
  -u YOUR_NOID_ADDRESS.RIG_NAME \
  -p x
```

## CPU-only command

```bash
./invminer --coin noid --cpu-only \
  -o stratum+ssl://stratum.innovlab.cc:19601 \
  -u YOUR_NOID_ADDRESS.RIG_NAME \
  -p x
```

This release supports only NOID and embeds only NOID CUDA modules. The
executable is always `invminer`, selected explicitly with `--coin noid`.

> **Binary-only risk:** this release may not work with every GPU, CPU, driver,
> OS, or future pool state. Source is not provided, so users cannot independently
> rebuild, audit, or patch it and must decide whether to trust the executable and
> published checksums. The software is provided without warranty.

## TLS behavior

NOID now accepts only WebPKI-verified TLS. Plaintext Stratum/TCP, insecure TLS,
and operator certificate pins are rejected before CPU/GPU device startup. A
valid public-CA certificate renewal for the same hostname, including a new leaf
key, requires no miner configuration change.

The RTX 4070 gate used default board controls and no clock arguments. Both

inside the same process from an injected loss of its only pool socket. The
official endpoint's newly issued public-CA certificate was accepted directly.

## HiveOS and runtime behavior

Use the exact canonical asset name above; HiveOS validates the Custom Miner
package name and the HiveOS asset therefore has no CUDA suffix. Use these
Custom Miner values:

- Miner name: `invminer`
- Installation URL: `https://github.com/getrigeos/INVminer-Release/releases/download/v0.1.51/invminer-0.1.51.tar.gz`
- Hash algorithm: `noid`
- Wallet and worker template: `%WAL%.%WORKER_NAME%`
- Pool URL: `stratum+ssl://stratum.innovlab.cc:19601`
- Pass: `x`
- Extra config arguments: leave empty unless ordinary runtime options are needed

The HiveOS archive follows `<miner-name>-<version>.tar.gz`; do not add tag `v`,
platform, architecture, HiveOS, or CUDA labels. Do not put a CUDA 12/13 package
URL in Extra config arguments. The adapter
reports aggregate and per-GPU statistics through the loopback API.
The final `invminer-0.1.51.tar.gz` archive was parsed as miner `invminer` and
version `0.1.51` on HiveOS, launched from its packaged adapter, reached the
configured pool, produced accepted shares with zero rejected shares, and passed
the HiveOS statistics adapter gate.

With no device list, supported GPUs use one shared user-pool connection and
non-overlapping search ranges. Normal commands do not require mining geometry,
CPU thread count, ISA flags, clock arguments, or `--state-dir`.

NOID uses a 5% developer fee measured from effective mining time. Waiting,
connection preparation failures and unavailable fee work are not charged. The
payout identity is not printed in normal logs or public documentation.

Extracting or running the package does not install or enable a boot service,
cron job, scheduled task, login/startup item, or container restart policy.

`sm_86/sm_89/sm_120`，要求 Linux Driver 580 或更新版本。兩個精確候選均已在 RTX
4070／Driver 580.178.04 使用預設硬體控制完成逐位自檢、取得 accepted share，已解析的
rejected 為零；CUDA 12 亦通過單一池連線中斷後同進程恢復門禁。

HiveOS 請使用標準套件 `invminer-0.1.51.tar.gz`，
Installation URL 使用上方完整下載位址；Hash algorithm 填 `noid`，Pool URL 使用頁首 TLS
入口，Template 填 `%WAL%.%WORKER_NAME%`，Pass 填 `x`，Extra config arguments 預設留空。
不要在 Extra config arguments 填入另一個 CUDA 下載位址。解壓或執行套件不會自行建立或
啟用任何開機服務或排程。本倉庫只提供閉源二進位，使用者需自行評估相容性與信任風險。
最終 `invminer-0.1.51.tar.gz` 已在 HiveOS 解析為 miner `invminer`、版本 `0.1.51`，
並從套件內 adapter 實際啟動；已連線、產生 accepted share、rejected 為零，且
HiveOS 統計 adapter 門禁通過。
