# INVminer v0.1.52

## GPU command

```bash
./invminer --coin noid \
  -o stratum+ssl://stratum.innovlab.cc:19601 \
  -u YOUR_NOID_ADDRESS.RIG_NAME \
  -p x
```

## CPU-only command

```bash
./invminer --coin noid --cpu-only \
  -o stratum+ssl://stratum.innovlab.cc:19601 \
  -u YOUR_NOID_ADDRESS.RIG_NAME \
  -p x
```

This release supports only NOID and embeds only NOID CUDA modules. The
executable is always `invminer`, selected explicitly with `--coin noid`.

> **Binary-only risk:** this release may not work with every GPU, CPU, driver,
> OS, or future pool state. Source is not provided, so users cannot independently
> rebuild, audit, or patch it and must decide whether to trust the executable and
> published checksums. The software is provided without warranty.

## TLS behavior

NOID uses WebPKI-verified TLS. Plaintext Stratum/TCP, insecure TLS, and operator
certificate pins are rejected before CPU/GPU device startup. A valid public-CA
certificate renewal for the same hostname, including a new leaf key, requires
no miner configuration change.

## HiveOS and runtime behavior

Use the exact canonical asset name above; HiveOS validates the Custom Miner
package name and the HiveOS asset therefore has no CUDA suffix. Use these
Custom Miner values:

- Miner name: `invminer`
- Installation URL: `https://github.com/getrigeos/INVminer-Release/releases/download/v0.1.52/invminer-0.1.52.tar.gz`
- Hash algorithm: `noid`
- Wallet and worker template: `%WAL%.%WORKER_NAME%`
- Pool URL: `stratum+ssl://stratum.innovlab.cc:19601`
- Pass: `x`
- Extra config arguments: leave empty unless ordinary runtime options are needed

The HiveOS archive follows `<miner-name>-<version>.tar.gz`; do not add tag `v`,
platform, architecture, HiveOS, or CUDA labels. Do not put a CUDA 12/13 package
URL in Extra config arguments. The adapter reports aggregate and per-GPU
statistics through the loopback API. The final `invminer-0.1.52.tar.gz` archive
was parsed as miner `invminer` and version `0.1.52` on HiveOS, launched from its
packaged adapter, reached the configured pool, produced accepted shares with
zero rejected shares, and passed the HiveOS statistics adapter gate.

With no device list, supported GPUs use one shared user-pool connection and
non-overlapping search ranges. Normal commands do not require mining geometry,
CPU thread count, ISA flags, clock arguments, or `--state-dir`.

NOID uses a 5% developer fee measured from effective mining time. Waiting,
connection preparation failures and unavailable fee work are not charged. The
payout identity is not printed in normal logs or public documentation.

Extracting or running the package does not install or enable a boot service,
cron job, scheduled task, login/startup item, or container restart policy.
