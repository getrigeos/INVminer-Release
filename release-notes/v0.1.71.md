# INVminer v0.1.71

## GPU command

```bash
./invminer --coin noid -o stratum+ssl://eu.innovlab.cc:19601 -u YOUR_NOID_ADDRESS.RIG_NAME
```

## CPU-only command

```bash
./invminer --coin noid --cpu-only -o stratum+ssl://eu.innovlab.cc:19601 -u YOUR_NOID_ADDRESS.RIG_NAME
```

The worker suffix and `-p/--pass` are optional. Use
`stratum+ssl://eu.innovlab.cc:19601` or
`stratum+ssl://hk.innovlab.cc:19601`. Public binaries accept only the approved
`innovlab.cc` and `01pool.com` TLS domain boundary.

> **Binary-only risk:** this release may not work with every GPU, CPU, driver,
> OS, or future pool state. Source is not provided, so users cannot independently
> rebuild, audit, or patch it and must decide whether to trust the executable and
> published checksums. The software is provided without warranty.

## Multi-pool recovery

Repeat `--pool`, or use a comma-separated list, to configure hot standby:

```bash
./invminer --coin noid --pool stratum+ssl://eu.innovlab.cc:19601 --pool stratum+ssl://hk.innovlab.cc:19601 --user YOUR_NOID_ADDRESS.RIG_NAME
```

INVminer keeps one steady mining connection. It rotates after bounded failures
and uses only short-lived probes before returning to a recovered primary. Two
consecutive successful probes are required by default; repeated flapping raises
the avoidance interval. It does not maintain a permanent standby session.

Every reconnect re-reads normal system name resolution, including `/etc/hosts`.
No public resolver or machine-specific DNS address is embedded. TLS certificate
chain and original-hostname verification remain mandatory; the miner never
downgrades TLS to plaintext. The same process continues retrying and recovers
after DNS, certificate, or pool service is corrected.

On the exact public HiveOS package, a four-pool EU/HK2/US/RU fault sequence
produced accepted work on each configured pool, returned to the primary after
successful probes, and kept one steady mining session. Final counters were 87
accepted, 2 stale, 0 rejected, with four reconnects. The maximum observed TCP
connection count was two only during a bounded probe. The PID remained unchanged
and `h-stats` passed.

## HiveOS

- Miner name: `invminer`
- Installation URL: `https://github.com/getrigeos/INVminer-Release/releases/download/v0.1.71/invminer-0.1.71.tar.gz`
- Hash algorithm: `noid`
- Pool URL: `stratum+ssl://eu.innovlab.cc:19601`
- Wallet template: `%WAL%.%WORKER_NAME%`
- Pass: leave empty
- Extra config arguments: leave empty for default controls

The CUDA 12/HiveOS package embeds reviewed native lanes for `sm_75`, `sm_80`,
`sm_86`, `sm_89`, and `sm_120`, including its CUDA 12.2 compatibility fallback.
The exact public/internal CUDA12/CUDA13 binaries passed CPU/GPU exact self-test
on RTX 4070. This release did not re-run physical multi-GPU, long stability, or
every historical GPU row above.

### HiveOS foreground troubleshooting

Use this only when normal startup is abnormal. It stops the managed miner when
present, creates a fresh temporary directory, and runs the current package in
the foreground. Replace only the wallet address; the worker suffix is optional.

`(miner stop || true) && cd "$(mktemp -d /tmp/171invminer.XXXXXX)" && wget -O invminer-0.1.71.tar.gz https://github.com/getrigeos/INVminer-Release/releases/download/v0.1.71/invminer-0.1.71.tar.gz && tar -xzf invminer-0.1.71.tar.gz && cd invminer && chmod +x invminer && ./invminer --coin noid --pool stratum+ssl://eu.innovlab.cc:19601 --user YOUR_NOID_ADDRESS --pass x`

### Manual upgrade for older HiveOS installations

Only some older HiveOS installations need this manual replacement. Use it only when HiveOS does not update the installed custom miner after the Installation URL is changed to this release.

```bash
miner stop && cd /tmp && rm -rf invminer && rm -f invminer-0.1.71.tar.gz && wget -O invminer-0.1.71.tar.gz https://github.com/getrigeos/INVminer-Release/releases/download/v0.1.71/invminer-0.1.71.tar.gz && tar -xzf invminer-0.1.71.tar.gz && mkdir -p /hive/miners/custom/invminer && rm -f /hive/miners/custom/invminer/invminer && cp -af invminer/. /hive/miners/custom/invminer/ && chmod +x /hive/miners/custom/invminer/invminer /hive/miners/custom/invminer/h-*.sh && /hive/miners/custom/invminer/invminer --version && miner start
```
