# INVminer v2.2.0.5

## Changes

- Add native Windows x64 support for Proxima upgrade-6, with an interactive account/worker launcher.

## Compatibility

**Windows x64, NVIDIA, Proxima upgrade-6 only, 0% developer fee.** This Windows-only release preserves ordered pool failover, primary recovery, rotate mode, device selection and local statistics. It uses the existing 2.2.0.4 search kernels; it does not claim a kernel speed increase. A CUDA-12-capable NVIDIA driver is required; installing CUDA Toolkit, Go or Python is unnecessary.

Linux/HiveOS users should keep [v2.2.0.4](https://github.com/getrigeos/INVminer-Release/releases/tag/v2.2.0.4). NOID/QUAN users should keep their separate package. The Windows ZIP is not a HiveOS installation URL.

## Windows setup

1. Extract the entire ZIP to a writable folder.
2. Open `invminer`, run `start-proxima.bat`, and enter your registered 64-hex Proxima holder/account ID. Do not enter a private key or seed. The default worker name is `winrig`.
3. For explicit worker and device selection, run in PowerShell:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\start-proxima.ps1 -Account YOUR_REGISTERED_64_HEX_ID -Worker winrig -Devices 0
```

The launcher uses these ordered endpoints:

- `stratum+ssl://global.innovlab.cc:19701`
- `stratum+ssl://eu3.innovlab.cc:19701`

For custom pools or rotate mode, use the executable directly:

```powershell
.\invminer.exe --coin proxima -o stratum+ssl://global.innovlab.cc:19701 -o stratum+ssl://eu3.innovlab.cc:19701 -u YOUR_REGISTERED_64_HEX_ID.winrig -p x --devices 0 --pool-failover-mode rotate --temp-limit 65 --temp-stop 70
```

The launcher pauses at 65 C, resumes at 60 C and requests shutdown at 70 C. It preserves existing GPU power/clock settings; the 100W qualification cap is not applied automatically. `-TempLimit` and `-TempStop` customize launcher thresholds. Statistics are available at `http://127.0.0.1:4068/stats`; use Ctrl+C to stop. Mining TLS preserves encryption and compatibility with self-signed pool certificates. HTTPS downloads retain normal certificate verification.
