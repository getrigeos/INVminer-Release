# INVminer v0.1.83

## GPU command

```bash
./invminer --coin quan -o stratum+ssl://eu2.innovlab.cc:17601 -u YOUR_QUANTUS_ADDRESS[.WORKER]
```

## CPU-only command

```bash
./invminer --coin noid --cpu-only -o stratum+ssl://eu.innovlab.cc:19601 -u YOUR_NOID_ADDRESS[.WORKER]
```

## NOID GPU command

```bash
./invminer --coin noid -o stratum+ssl://eu.innovlab.cc:19601 -u YOUR_NOID_ADDRESS[.WORKER]
```

`--coin noid` or `--coin quan` is required. The worker suffix and `--pass` are
optional; an omitted password uses the compatible value `x`.

> **Binary-only risk:** this release may not work with every GPU, CPU, driver,
> OS, or future pool state. Source is not provided, so users cannot independently
> rebuild, audit, or patch it. The software is provided without warranty.

## Changes

- The official QUAN endpoint now uses the LuckyPool-compatible Full256 protocol.
  `eu2.innovlab.cc:17601` selects its `login` / `job` / `submit` dialect
  automatically and uses this dialect directly.
- Jobs are checked for the expected algorithm, four-byte extranonce, sequence,
  difficulty and matching 512-bit target before GPU work starts.
- NVIDIA CMP 40HX now uses a qualified native SM75 path with exact model
  dispatch. Existing qualified NVIDIA paths remain in the unified executable.
- A HiveOS host-and-port-only Pool URL now defaults to authenticated TLS.
  Plaintext requires an explicit `stratum+tcp://` URL.
- Compatible third-party QUAN QUIC, TCP and TLS pools remain selectable. Pool
  hostnames are resolved for each connection; resolved IP addresses are not
  embedded.
- QUAN keeps the disclosed 3% developer fee over the official Quanpool hostname.
  NOID remains at 1%.

## Validation and boundaries

- CUDA 12 and CUDA 13 were each built twice from one frozen source commit in an
  offline pinned container; matching flavors were byte-identical.
- The exact public CUDA 12/HiveOS artifact passed native QUAN CPU/GPU self-test,
  WebPKI TLS login, live accepted-share accounting with zero rejected or stale
  shares, and HiveOS statistics on NVIDIA CMP 40HX.
- This release does not publish a numerical performance claim.
- Linux x86_64 requires glibc 2.30 or newer. Use the CUDA 12 package for broad
  driver compatibility. RTX 50 series requires a Blackwell-capable driver.

## HiveOS flight sheet

- Miner: Custom → `invminer`
- Installation URL: `https://github.com/getrigeos/INVminer-Release/releases/download/v0.1.83/invminer-0.1.83.tar.gz`
- Coin: Custom
- Hash algorithm: `quan` for QUAN or `noid` for NOID
- QUAN Pool URL: `eu2.innovlab.cc:17601` (host-and-port-only defaults to authenticated TLS)
- NOID Pool URL: `eu.innovlab.cc:19601` (host-and-port-only defaults to authenticated TLS)
- Wallet template: `%WAL%.%WORKER_NAME%`
- Pass: `x`
- Extra config arguments: empty by default; add only optional INVminer flags

All visible GPUs are used automatically; do not add `--devices` unless you want
an explicit subset.

### Foreground troubleshooting

For abnormal startup only: stop the managed miner if present, download into a
new random directory, and show errors in the foreground. Replace the wallet
address and select the intended coin after startup is confirmed.

`(miner stop || true) && cd "$(mktemp -d /tmp/183invminer.XXXXXX)" && wget -O invminer-0.1.83.tar.gz https://github.com/getrigeos/INVminer-Release/releases/download/v0.1.83/invminer-0.1.83.tar.gz && tar -xzf invminer-0.1.83.tar.gz && cd invminer && chmod +x invminer && ./invminer --coin noid --pool stratum+ssl://eu.innovlab.cc:19601 --user YOUR_NOID_ADDRESS --pass x`

### Older HiveOS manual replacement

Only some older HiveOS installations need this manual replacement. Use it only when HiveOS does not update the installed custom miner after the Installation URL is changed to this release.

```bash
miner stop && cd /tmp && rm -rf invminer && rm -f invminer-0.1.83.tar.gz && wget -O invminer-0.1.83.tar.gz https://github.com/getrigeos/INVminer-Release/releases/download/v0.1.83/invminer-0.1.83.tar.gz && tar -xzf invminer-0.1.83.tar.gz && mkdir -p /hive/miners/custom/invminer && rm -f /hive/miners/custom/invminer/invminer && cp -af invminer/. /hive/miners/custom/invminer/ && chmod +x /hive/miners/custom/invminer/invminer /hive/miners/custom/invminer/h-*.sh && /hive/miners/custom/invminer/invminer --version && miner start
```

## 繁體中文

v0.1.83 將官方 QUAN TLS 端點切換到與 LuckyPool 相容的 Full256 協議，並加入
NVIDIA CMP 40HX 的合格原生 SM75 路徑。工作在送入 GPU 前會核對演算法、四位元組
extranonce、序號、難度及相符的 512 位元 target。HiveOS 的主機加連接埠 Pool URL
現在預設使用驗證式 TLS；只有明確填寫 `stratum+tcp://` 才使用明文。

正式 CUDA 12/HiveOS 制品已在 CMP 40HX 通過原生 GPU/CPU 自檢、WebPKI TLS 實池
登入、Accepted 且零 Rejected/Stale，以及 HiveOS 統計驗收。本版不發布數值算力聲明。
解壓或執行 INVminer 不會安裝或啟用開機服務、排程、登入項目、cron 或自動重啟規則。

### 舊版 HiveOS 手動升級

僅部分舊版 HiveOS 需要此手動覆蓋；只有在更新 Installation URL 後仍未替換已安裝的 Custom Miner 時才執行。

符合上述情況時，執行上方 Older HiveOS manual replacement 的單行命令。
