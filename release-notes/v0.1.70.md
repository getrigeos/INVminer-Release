# INVminer v0.1.70

## GPU command

```bash
./invminer --coin noid \
  -o stratum+ssl://eu.innovlab.cc:19601 \
  -u YOUR_NOID_ADDRESS.RIG_NAME
```

## CPU-only command

```bash
./invminer --coin noid --cpu-only \
  -o stratum+ssl://eu.innovlab.cc:19601 \
  -u YOUR_NOID_ADDRESS.RIG_NAME
```

Use `stratum+ssl://eu.innovlab.cc:19601` or
`stratum+ssl://hk.innovlab.cc:19601`. `-p/--pass` is optional. Public binaries
accept only the approved `innovlab.cc` and `01pool.com` TLS domain boundary.

> **Binary-only risk:** this release may not work with every GPU, CPU, driver,
> OS, or future pool state. Source is not provided, so users cannot independently
> rebuild, audit, or patch it and must decide whether to trust the executable and
> published checksums. The software is provided without warranty.

## Pool-service recovery

Temporary DNS, certificate, or pool-service failures no longer require a miner
restart. The same process retries with bounded backoff, re-resolves the pool
hostname, and resumes after the service and its valid certificate are restored.
TLS certificate-chain and exact hostname verification remain enabled on every
connection; the miner never downgrades TLS to plaintext.

The exact v0.1.70 HiveOS package reached accepted work, stayed alive through a
60-second complete pool outage, and recovered from accepted `2` to `3` with one
recorded reconnect, zero rejected work, no active session error after recovery,
and passing HiveOS statistics.

Recorded drivers were `580.178.04` for CMP 50HX, RTX 3080 and RTX 4070, and
`595.84` for A100, RTX 4090 and RTX 5090. Apply a tuned row only to its exact
GPU model. The reviewed INVminer extra arguments are:

```text
RTX 3080: --power-limit 320 --lock-mem 810 --core-clock-offset 260
RTX 4090: --power-limit 450 --lock-mem 810 --core-clock-offset 250
RTX 5090: --power-limit 575 --lock-mem 810 --core-clock-offset 400
```

Core offset may require `--nvidia-display` and `--nvidia-xauthority` when the
X11 session cannot be discovered automatically. Start with a lower offset and
increase only after checking temperature, accepted work, and stability. If an
optional setting cannot be applied, INVminer warns and continues only from a
verified default/original state; settings applied by INVminer are restored when
the process exits.

## HiveOS

- Miner name: `invminer`
- Installation URL: `https://github.com/getrigeos/INVminer-Release/releases/download/v0.1.70/invminer-0.1.70.tar.gz`
- Hash algorithm: `noid`
- Pool URL: `stratum+ssl://eu.innovlab.cc:19601`
- Wallet template: `%WAL%.%WORKER_NAME%`
- Pass: leave empty
- Extra config arguments: leave empty for default controls

The CUDA 12/HiveOS package embeds reviewed native lanes for `sm_75`, `sm_80`,
`sm_86`, `sm_89`, and `sm_120`, including the CUDA 12.2 compatibility fallback.
The four exact public/internal CUDA12/CUDA13 binaries passed CPU/GPU exact
self-test on RTX 4070. This release did not re-run physical multi-GPU, long
stability, or every GPU model listed above.

### HiveOS foreground troubleshooting

If normal startup is abnormal, run this once in the HiveOS shell. It stops the
managed miner when present and keeps INVminer in the foreground so the terminal
shows the connection, CUDA, and share error. Replace only the wallet address;
the worker suffix is optional.

```bash
(miner stop || true) && mkdir /tmp/170invminer && cd /tmp/170invminer && wget -O invminer-0.1.70.tar.gz https://github.com/getrigeos/INVminer-Release/releases/download/v0.1.70/invminer-0.1.70.tar.gz && tar -xzf invminer-0.1.70.tar.gz && cd invminer && chmod +x invminer && ./invminer --coin noid --pool stratum+ssl://eu.innovlab.cc:19601 --user YOUR_NOID_ADDRESS --pass x
```

### Manual upgrade for older HiveOS installations

Only some older HiveOS installations need this manual replacement. Use it only when HiveOS does not update the installed custom miner after the Installation URL is changed to this release.

```bash
miner stop && cd /tmp && rm -rf invminer && rm -f invminer-0.1.70.tar.gz && wget -O invminer-0.1.70.tar.gz https://github.com/getrigeos/INVminer-Release/releases/download/v0.1.70/invminer-0.1.70.tar.gz && tar -xzf invminer-0.1.70.tar.gz && mkdir -p /hive/miners/custom/invminer && rm -f /hive/miners/custom/invminer/invminer && cp -af invminer/. /hive/miners/custom/invminer/ && chmod +x /hive/miners/custom/invminer/invminer /hive/miners/custom/invminer/h-*.sh && /hive/miners/custom/invminer/invminer --version && miner start
```
