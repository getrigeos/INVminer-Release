# INVminer v0.1.64

## GPU command

```bash
./invminer --coin noid \
  -o stratum+ssl://eu.innovlab.cc:19601 \
  -u YOUR_NOID_ADDRESS.RIG_NAME
```

## CPU-only command

```bash
./invminer --coin noid --cpu-only \
  -o stratum+ssl://eu.innovlab.cc:19601 \
  -u YOUR_NOID_ADDRESS.RIG_NAME
```

Pool website: <https://noid.innovlab.cc/>. The Hong Kong endpoint is
`stratum+ssl://hk.innovlab.cc:19601`. `-p/--pass` is optional.

## Tested GPU performance

Final public v0.1.64 assets, one physical GPU, a warm card, and a 60-second
measurement window:

| GPU | Package / controls | Power cap | Memory lock | Core offset | Rate |
|---|---|---:|---:|---:|---:|
| RTX 3080 10GB | Linux CUDA 12; default controls | 320 W | Default | 0 | 57.823 MH/s |
| RTX 4070 | HiveOS / CUDA 12; default controls | 200 W | Default | 0 | 56.243 MH/s |
| RTX 4090 | Linux CUDA 13; INVminer tuning | 450 W | 810 MHz | +250 MHz | 161.054 MH/s |
| RTX 5090 | Linux CUDA 13; INVminer tuning | 575 W | 810 MHz | +400 MHz | 231.271 MH/s |

These are sample-card results, not guarantees. The RTX 4090 and RTX 5090
profiles were applied by INVminer with these extra arguments:

```text
RTX 4090: --power-limit 450 --lock-mem 810 --core-clock-offset 250
RTX 5090: --power-limit 575 --lock-mem 810 --core-clock-offset 400
```

Apply a tuning row only to its exact GPU model. Reduce the offset if the card is
unstable or thermally constrained. INVminer restores its applied controls when
the process exits; an unavailable optional control warns and mining continues
only from a verified safe/default state.

The final RTX 3080 and RTX 4070 binaries selected native SASS and passed the
CPU/GPU exact self-test. The RTX 3080 production TLS run reached `ONLINE` with
accepted work and no rejected work. The exact canonical HiveOS archive passed
its RTX 4070 live gate with empty Pass, `ONLINE`, accepted work, zero rejected
work, and working `h-stats`. The final tuned RTX 4090 and RTX 5090 runs also
passed the exact self-test and restored idle/default hardware state afterward.

## HiveOS

- Miner name: `invminer`
- Installation URL: `https://github.com/getrigeos/INVminer-Release/releases/download/v0.1.64/invminer-0.1.64.tar.gz`
- Hash algorithm: `noid`
- Pool URL: `stratum+ssl://eu.innovlab.cc:19601`
- Wallet template: `%WAL%.%WORKER_NAME%`
- Pass: leave empty
- Extra config arguments: leave empty for default controls

### Manual upgrade for older HiveOS installations

Only some older HiveOS installations need this manual replacement. Use it only when HiveOS does not update the installed custom miner after the Installation URL is changed to this release.

```bash
miner stop && cd /tmp && rm -rf invminer && rm -f invminer-0.1.64.tar.gz && wget -O invminer-0.1.64.tar.gz https://github.com/getrigeos/INVminer-Release/releases/download/v0.1.64/invminer-0.1.64.tar.gz && tar -xzf invminer-0.1.64.tar.gz && mkdir -p /hive/miners/custom/invminer && rm -f /hive/miners/custom/invminer/invminer && cp -af invminer/. /hive/miners/custom/invminer/ && chmod +x /hive/miners/custom/invminer/invminer /hive/miners/custom/invminer/h-*.sh && /hive/miners/custom/invminer/invminer --version && miner start
```

## 顯卡實測

以下均為公開 v0.1.64 最終資產、單張實體顯卡、熱卡及 60 秒計時：

| GPU | 套件／控制 | 功率牆 | 顯存鎖定 | 核心 offset | 算力 |
|---|---|---:|---:|---:|---:|
| RTX 3080 10GB | Linux CUDA 12；預設控制 | 320 W | 預設 | 0 | 57.823 MH/s |
| RTX 4070 | HiveOS／CUDA 12；預設控制 | 200 W | 預設 | 0 | 56.243 MH/s |
| RTX 4090 | Linux CUDA 13；INVminer 調優 | 450 W | 810 MHz | +250 MHz | 161.054 MH/s |
| RTX 5090 | Linux CUDA 13；INVminer 調優 | 575 W | 810 MHz | +400 MHz | 231.271 MH/s |

結果只代表實測樣卡，不保證每張卡相同。4090／5090 僅使用上方對應型號的參數；不穩定或散熱受限時
請降低 offset。歐洲與香港節點都必須使用 `stratum+ssl://`，`--pass` 並非必填。
