# INVminer v0.2.22

公开版仅包含 **NOID / QUAN**，不包含 Pearl GPU 内核。公开版与私有版采用相同的 NOID/QUAN 实现和矿池兼容能力；第三方兼容矿池开放，旧的官方池限定等历史门禁已移除。

开发费：**NOID 1%、QUAN 5%**（公开版 QUAN 从 v0.1.85 的 2% 更新为 5%）。裸 `host:port` 自动判断 TCP/TLS；显式 URL 协议优先。

- [HiveOS 统一安装包](https://github.com/getrigeos/INVminer-Release/releases/download/v0.2.22/invminer-0.2.22.tar.gz)：自动选择内置 CUDA12/13。
- [Linux CUDA12](https://github.com/getrigeos/INVminer-Release/releases/download/v0.2.22/invminer-v0.2.22-linux-x86_64-cuda12.tar.gz)
- [Linux CUDA13](https://github.com/getrigeos/INVminer-Release/releases/download/v0.2.22/invminer-v0.2.22-linux-x86_64-cuda13.tar.gz)

双 CUDA 各两轮构建、三种包各两轮打包一致；最终 HiveOS 包通过 CMP40HX 上的 NOID CUDA12、QUAN CUDA12/13 自检及自动选择检查；40HX 的 NOID 自动使用 CUDA12，CUDA13 不支持该币种的 SM75 路径。此次未重新进行完整机型矩阵或矿池性能测试。

Public distribution includes NOID and QUAN only; Pearl GPU kernels are excluded. Compatible third-party pools are supported. Developer fees are NOID 1% and QUAN 5%. The unified HiveOS archive selects the appropriate bundled CUDA executable. Both flavors and all archives were reproduced twice; NOID CUDA12 and QUAN CUDA12/13 self-tests plus automatic selection passed on CMP40HX. NOID on SM75 uses CUDA12. Archive signatures use the same filename with `.sig` appended.
