# INVminer v0.2.22

## Changes

- Improve NOID mining performance on NVIDIA GeForce RTX 4090. The optimized path is selected automatically with a CUDA 13-capable driver.

## GPU command

```bash
./invminer --coin quan -o stratum+ssl://eu2.innovlab.cc:17601 -u YOUR_QUANTUS_ADDRESS[.WORKER]
```

## CPU-only command

```bash
./invminer --coin noid --cpu-only -o stratum+ssl://eu.innovlab.cc:19601 -u YOUR_NOID_ADDRESS[.WORKER]
```

## NOID GPU command

```bash
./invminer --coin noid -o stratum+ssl://eu.innovlab.cc:19601 -u YOUR_NOID_ADDRESS[.WORKER]
```

`--coin noid` or `--coin quan` is required. The worker suffix and `--pass` are optional; an omitted password uses `x`.

Developer fees: NOID **1%**, QUAN **5%**.

## HiveOS flight sheet

- Miner: Custom → `invminer`
- Installation URL: `https://github.com/getrigeos/INVminer-Release/releases/download/v0.2.22/invminer-0.2.22.tar.gz`
- Coin: Custom
- Hash algorithm: `quan` for QUAN or `noid` for NOID
- QUAN Pool URL: `eu2.innovlab.cc:17601`
- NOID Pool URL: `eu.innovlab.cc:19601`
- Wallet template: `%WAL%.%WORKER_NAME%`
- Pass: `x`
- Extra config arguments: empty by default

All visible GPUs are used automatically; add `--devices` only to select a subset.
